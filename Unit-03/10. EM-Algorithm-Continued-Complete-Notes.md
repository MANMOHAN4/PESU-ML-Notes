## What is the EM Algorithm

### Definition

**Expectation-Maximization (EM)** is an iterative algorithm to learn maximum likelihood (or maximum a posteriori) estimates of parameters in statistical models with latent (hidden/missing) variables.

### Key Characteristics

- **Iterative Process:** Repeats E-step and M-step until convergence
- **Handles Hidden Data:** Works when some data is unobserved or latent
- **Parameter Estimation:** Finds model parameters that best explain the data
- **Used in Complex Models:** Situations where direct optimization is infeasible

### Why EM?

In models with latent variables:
- Cannot directly count or observe hidden values
- Need to estimate what hidden values might be
- Use estimates to improve parameter guesses
- Repeat until stable

### The Chicken-and-Egg Problem

**Central Challenge:**
```
To estimate parameters:   Need complete data
But to get complete data: Need parameter estimates
```

**EM Solution:** Start with guess, iteratively improve both

## Applications of EM

### Real-World Use Cases

1. **Hidden Markov Models (HMMs)**
   - Hidden states are unobserved
   - Use EM to estimate transition probabilities (A) and emission probabilities (B)
   - Application: Speech recognition, part-of-speech tagging

2. **Gaussian Mixture Models (GMM)**
   - Assume data comes from mixture of Gaussians
   - Unknown which Gaussian generated each point
   - Use EM to find Gaussian parameters (μ, σ)
   - Application: Clustering, density estimation

3. **K-Means Clustering**
   - Special case of EM with simplified assumptions
   - Alternates between assigning points to clusters and updating cluster centers

4. **Missing Data Problems**
   - Incomplete surveys or datasets
   - Some values are missing (latent)
   - EM estimates missing values and learns model

5. **Other Applications**
   - Latent factor models
   - Topic modeling
   - Collaborative filtering
   - Medical diagnosis with hidden disease states

## Two-Step EM Approach

### The EM Algorithm Structure

```
Initialize parameters with random values
Repeat until convergence:
  1. E-STEP (Expectation):
     Estimate the latent/missing data using:
     - Current parameter estimates
     - Observed data
     Result: Expected values/probabilities of missing data
  
  2. M-STEP (Maximization):
     Maximize likelihood function assuming:
     - Missing data is known
     Use estimated missing data from E-step
     Result: Updated parameter estimates
```

### Key Insight

Instead of:
- Trying to optimize with unknown data
- Getting stuck

EM does:
- Estimate missing data (E-step)
- Optimize assuming estimates are correct (M-step)
- Repeat, improving estimates each time

### Convergence

- Each iteration increases likelihood (monotonic improvement)
- Eventually converges to local maximum
- Usually converges in 10-100 iterations

## The Coin Flipping Problem - Introductory Example

### Problem Setup

**Scenario:** You have two coins labeled A and B
- **Goal:** Estimate bias of each coin (probability of heads)
- **Challenge:** Don't always know which coin was used

**Parameters to Estimate:**
- θₐ = P(heads | coin A)
- θᵦ = P(heads | coin B)

---

## Known Coin Identity Case

### When We Know Which Coin Was Used

**Given Data:**
```
Trial 1 (Coin B): H T T T H H T H T H  → 5 heads out of 10
Trial 2 (Coin A): H H H H T H H H H H  → 9 heads out of 10
Trial 3 (Coin A): H T H H H H H T H H  → 8 heads out of 10
Trial 4 (Coin B): H T H T T T H H T T  → 4 heads out of 10
Trial 5 (Coin A): T H H H T H H H T H  → 7 heads out of 10
```

### Step 1: Count Successes

**For Coin A (Trials 2, 3, 5):**
```
Total heads = 9 + 8 + 7 = 24
Total flips = 10 + 10 + 10 = 30
```

**For Coin B (Trials 1, 4):**
```
Total heads = 5 + 4 = 9
Total flips = 10 + 10 = 20
```

### Step 2: Calculate Maximum Likelihood Estimates

**Coin A:**
```
θₐ = 24/30 = 0.8
```

**Coin B:**
```
θᵦ = 9/20 = 0.45
```

### Simple Solution

When coin identity is known, we simply count heads and tails for each coin. This is straightforward maximum likelihood estimation.

## Unknown Coin Identity Case - The Latent Variable Problem

### The Challenge

**Same data as before, but now:**
```
Trial 1: H T T T H H T H T H  → ? heads (unknown coin)
Trial 2: H H H H T H H H H H  → ? heads (unknown coin)
Trial 3: H T H H H H H T H H  → ? heads (unknown coin)
Trial 4: H T H T T T H H T T  → ? heads (unknown coin)
Trial 5: T H H H T H H H T H  → ? heads (unknown coin)
```

### The Problem

- We can't simply count heads for each coin
- Don't know which coin generated each sequence
- **Latent Variable:** Coin identity is hidden

### Why EM is Needed

```
If we knew coin identity: → Could estimate parameters (Count heads/tails)
But we need parameters: → To estimate coin identity
Solution: EM alternates between both
```

## Step-by-Step Solution: Coin Flipping with Unknown Identities

### Iteration 0: Initialize with Random Guess

We start by guessing parameter values randomly:
```
θₐ⁽⁰⁾ = 0.6  (guess: coin A biased toward heads)
θᵦ⁽⁰⁾ = 0.5  (guess: coin B fair)
P(A) = 0.5, P(B) = 0.5  (equal probability of each coin)
```

### Iteration 1: E-Step (Expectation)

**Goal:** Estimate which coin generated each sequence

**For Trial 1: E = H T T T H H T H T H (5 heads, 5 tails)**

**Step 1: Calculate likelihood under each coin**

```
P(E|A) = P(5 heads, 5 tails | θₐ=0.6)
       = C(10,5) × (0.6)⁵ × (0.4)⁵
       = 252 × 0.07776 × 0.01024
       = 0.2006

P(E|B) = P(5 heads, 5 tails | θᵦ=0.5)
       = C(10,5) × (0.5)⁵ × (0.5)⁵
       = 252 × 0.03125 × 0.03125
       = 0.2461
```

**Step 2: Apply Bayes Theorem to get posterior probability**

```
P(A|E) = P(E|A) × P(A) / [P(E|A) × P(A) + P(E|B) × P(B)]
       = 0.2006 × 0.5 / [0.2006 × 0.5 + 0.2461 × 0.5]
       = 0.1003 / 0.2234
       = 0.45

P(B|E) = 0.2461 × 0.5 / 0.2234
       = 0.55
```

**Interpretation:** Trial 1 has 45% chance of being Coin A, 55% chance of being Coin B

**Step 3: Attribute heads to each coin proportionally**

```
Expected heads from A = 5 × 0.45 = 2.25
Expected heads from B = 5 × 0.55 = 2.75
Expected tails from A = 5 × 0.45 = 2.25
Expected tails from B = 5 × 0.55 = 2.75
```

### Complete E-Step Calculation Table

For all 5 trials:

| Trial | Sequence | P(A) | P(B) | E[H\|A] | E[T\|A] | E[H\|B] | E[T\|B] |
|-------|----------|------|------|---------|---------|---------|---------|
| 1 | HTTTHHTHT | 0.45 | 0.55 | 2.25 | 2.75 | 2.75 | 2.25 |
| 2 | HHHHTHHHH | 0.80 | 0.20 | 7.2 | 0.8 | 1.8 | 0.2 |
| 3 | HTHHHHTHN | 0.73 | 0.27 | 5.84 | 1.46 | 2.16 | 0.54 |
| 4 | HTHTTTHTT | 0.35 | 0.65 | 1.4 | 2.6 | 2.6 | 1.4 |
| 5 | THHHTHHHТ | 0.65 | 0.35 | 4.55 | 2.45 | 2.45 | 2.55 |

**Totals:**
```
Coin A: 21.24 heads, 8.76 tails
Coin B: 11.76 heads, 8.94 tails
```

### Iteration 1: M-Step (Maximization)

**Update parameters using expected counts:**

```
θₐ⁽¹⁾ = Total expected heads for A / Total expected flips for A
      = 21.24 / (21.24 + 8.76)
      = 21.24 / 30
      = 0.708

θᵦ⁽¹⁾ = Total expected heads for B / Total expected flips for B
      = 11.76 / (11.76 + 8.94)
      = 11.76 / 20.7
      = 0.567
```

**New estimates:**
```
θₐ⁽¹⁾ = 0.708
θᵦ⁽¹⁾ = 0.567
```

### Iteration 2 and Beyond

Repeat E-step with new parameters:
```
E-step: Recalculate P(A|each trial) and P(B|each trial) with new θ values
M-step: Update θₐ and θᵦ again

Continue until θₐ⁽ⁿ⁾ ≈ θₐ⁽ⁿ⁻¹⁾ and θᵦ⁽ⁿ⁾ ≈ θᵦ⁽ⁿ⁻¹⁾
```

## EM Algorithm Summary

### Two Core Steps

**E-Step (Expectation):**
1. Use current parameter estimates
2. Calculate probability each missing data value could have
3. Expected value = weighted average based on these probabilities
4. Result: Estimated missing data

**M-Step (Maximization):**
1. Treat estimated missing data as if it were known
2. Use standard maximum likelihood estimation
3. Recalculate parameters
4. Result: Updated parameters

### Why It Works

- **Monotonic Improvement:** Likelihood increases (or stays same) each iteration
- **Convergence:** Eventually reaches local maximum
- **Guaranteed:** Won't diverge or oscillate

### Advantages

✅ Handles latent variables naturally  
✅ Principled probabilistic approach  
✅ Theoretically justified  
✅ Works for complex models  

### Disadvantages

❌ Computationally expensive  
❌ Only finds local maxima  
❌ Needs reasonable initial guess  
❌ Convergence can be slow  

### When to Use

- Complex probabilistic models
- Missing or latent data
- Mixture models
- Clustering with uncertainty
- Hidden Markov Models

### Connection to Other Algorithms

- **Baum-Welch Algorithm:** EM applied to HMMs
- **K-Means:** Special case of EM with hard assignments
- **Gibbs Sampling:** Alternative to EM

## Practical Tips

### Initialization

- Try multiple random initializations
- Use domain knowledge if available
- Avoid extreme values (0 or 1)

### Convergence

- Check likelihood (should increase)
- Monitor parameter changes (should decrease)
- Typical convergence: 10-100 iterations
- Set tolerance threshold for stopping

### Numerical Stability

- Work in log-space when possible
- Avoid very small probability values
- Use normalized calculations

### Validation

- Check if parameters make sense
- Verify likelihood increases
- Compare multiple initializations
- Validate on test data

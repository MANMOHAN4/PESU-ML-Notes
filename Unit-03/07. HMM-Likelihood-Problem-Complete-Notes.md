## Problem Statement

### The Likelihood Problem
**Given:**
- Hidden Markov Model λ(π, A, B)
- Observation sequence O = {o₁, o₂, ..., oₜ}

**Find:**
- P(O | λ) - Probability of observing this sequence given the model

### Why This Problem Matters

**Applications:**
1. **Model Comparison:** Given multiple HMMs, select the best one (highest likelihood on test data)
2. **Anomaly Detection:** Low likelihood indicates unusual observation sequence
3. **Diagnosis:** Likelihood scores help determine if patient's symptom sequence is typical
4. **Validation:** Evaluate how well trained model explains test data

### Example
- Patient visits hospital with symptom sequence: [Healthy, Mild Symptoms, Severe, Hospitalized]
- Question: "Is this progression typical?" (Calculate likelihood given trained disease HMM)
- High likelihood → typical progression
- Low likelihood → unusual, requires investigation

## Brute Force Solution

### Approach
For every possible hidden state sequence Q of length T:
1. Calculate P(O | Q) - probability of observations given this state sequence
2. Calculate P(Q) - probability of this state sequence
3. Combine: P(O, Q) = P(O | Q) × P(Q)
4. Sum over all possible state sequences to get P(O)

### Mathematical Formulation

**For a specific state sequence Q = {q₁, q₂, ..., qₜ}:**
```
P(O, Q) = P(O | Q) × P(Q)

Where:
P(O | Q) = ∏ᵢ P(oᵢ | qᵢ) = b_q1(o1) × b_q2(o2) × ... × b_qT(oT)

P(Q) = π_q1 × a_q1,q2 × a_q2,q3 × ... × a_qT-1,qT

Therefore:
P(O, Q) = π_q1 × b_q1(o1) × a_q1,q2 × b_q2(o2) × a_q2,q3 × ... × b_qT(oT)
```

**Final probability:**
```
P(O | λ) = ∑_Q P(O, Q) = ∑_Q [π_q1 × ∏ᵢ(aᵢ,ᵢ₊₁ × b_i+1(oᵢ₊₁))]
```

### Computational Complexity

**Calculations per sequence:**
- Each state sequence requires: 2T - 1 multiplications (approximately 2T)

**Total operations:**
- Number of sequences: N^T (N states, T time steps)
- Operations per sequence: 2T
- **Total: O(T × N^T) multiplications**

**Example Complexity:**
- N = 2 states, T = 3 steps: 2 × 3 × 2³ = 2 × 3 × 8 = 48 operations
- N = 10 states, T = 10 steps: 10 × 2 × 10^10 = 2 × 10^11 operations (infeasible!)
- **Exponential complexity makes brute force impractical**

## Computational Complexity Analysis

### The Problem with Brute Force

For a simple HMM with N=2 states and T=3 observations:

**All possible state sequences (2^3 = 8):**
```
SSS, SSR, SRS, SRR, RSS, RSR, RRS, RRR
(S = Sunny, R = Rainy)
```

**Complete expansion:**
```
P(O) = π(S)b_S(o1)a_SS b_S(o2)a_SS b_S(o3)  +
       π(S)b_S(o1)a_SS b_S(o2)a_SR b_R(o3)  +
       π(S)b_S(o1)a_SR b_R(o2)a_RS b_S(o3)  +
       π(S)b_S(o1)a_SR b_R(o2)a_RR b_R(o3)  +
       π(R)b_R(o1)a_RS b_S(o2)a_SS b_S(o3)  +
       π(R)b_R(o1)a_RS b_S(o2)a_SR b_R(o3)  +
       π(R)b_R(o1)a_RR b_R(o2)a_RS b_S(o3)  +
       π(R)b_R(o1)a_RR b_R(o2)a_RR b_R(o3)
```

**Observation:** Many terms repeat!
- π(S)b_S(o1) appears in first 4 terms
- a_SS b_S(o2) appears in multiple terms
- Can we exploit this structure?

### Solution: Dynamic Programming

**Key Insight:** Reuse intermediate calculations!

Instead of recalculating everything for each complete sequence, compute partial results once and reuse them.

## Forward Algorithm

### Core Idea
Compute probability incrementally from left to right (forward in time).

### Definition: Alpha (α) Variable

**αₜ(j) = P(o₁, o₂, ..., oₜ, qₜ = j | λ)**

**Interpretation:**
- Joint probability of:
  - Observing symbols o₁ through oₜ
  - AND being in state j at time t
  - Given the model λ

### Recursive Computation

**Initialization (t=1):**
```
α₁(j) = πⱼ × b_j(o₁)
```

**Recursion (t=2 to T):**
```
αₜ(j) = [∑ᵢ αₜ₋₁(i) × aᵢⱼ] × b_j(oₜ)
```

**Termination:**
```
P(O | λ) = ∑_j αₜ(j)
```

### Computational Complexity

**Time complexity:**
- At each time step t: N states × N previous states = O(N²)
- Total for T steps: O(N² × T)
- **Dramatically better than O(T × N^T) brute force!**

Example: N=2, T=10
- Brute force: ~20 × 2^10 ≈ 20,000 operations
- Forward: 2² × 10 = 40 operations

### Forward Algorithm Pseudocode

```
procedure FORWARD(observations of len T, state-graph of len N):
    forward ← new matrix[N][T]
    
    // Initialization
    for states s from 1 to N do
        forward[s, 1] ← π_s × b_s(o₁)
    
    // Recursion
    for timestamp t from 2 to T do
        for states j from 1 to N do
            forward[j, t] ← 0
            for previous states i from 1 to N do
                forward[j, t] ← forward[j, t] + forward[i, t-1] × a_{i,j}
            forward[j, t] ← forward[j, t] × b_j(o_t)
    
    // Termination
    forwardProb ← 0
    for states j from 1 to N do
        forwardProb ← forwardProb + forward[j, T]
    
    return forwardProb
```

## Backward Algorithm

### Core Idea
Compute probability incrementally from right to left (backward in time).

### Definition: Beta (β) Variable

**βₜ(i) = P(oₜ₊₁, oₜ₊₂, ..., oₜ | qₜ = i, λ)**

**Interpretation:**
- Probability of observing symbols from t+1 to end
- Given that we're currently in state i at time t
- Looking forward from current position

### Recursive Computation

**Initialization (t=T):**
```
βₜ(i) = 1 for all states i
```

**Recursion (t=T-1 down to 1):**
```
βₜ(i) = ∑ⱼ aᵢⱼ × b_j(oₜ₊₁) × βₜ₊₁(j)
```

### Backward Algorithm Pseudocode

```
procedure BACKWARD(observations of len T, state-graph of len N):
    backward ← new matrix[N][T]
    
    // Initialization
    for states i from 1 to N do
        backward[i, T] ← 1
    
    // Recursion (going backward)
    for timestamp t from T-1 down to 1 do
        for states i from 1 to N do
            backward[i, t] ← 0
            for next states j from 1 to N do
                backward[i, t] ← backward[i, t] + a_{i,j} × b_j(o_{t+1}) × backward[j, t+1]
    
    return backward
```

## Verification Using Forward and Backward

### Important Mathematical Result

**Relationship:**
```
P(O | λ) = αₜ(i) × βₜ(i)  for any time t and any state i
```

**Why this works:**
- αₜ(i) = probability of observations up to time t in state i
- βₜ(i) = probability of observations from t+1 onward given state i
- Product = total probability (marginalizing over state at time t)

### Verification Process

**Example:** Observation sequence O = {H, G, H}

**Using Forward Algorithm (t=1):**
```
Forward values at t=1:
α₁(Sunny) = 0.5333
α₁(Rainy) = 0.1333

Backward values at t=1:
β₁(Sunny) = 0.1824
β₁(Rainy) = 0.2592

P(O|λ) = α₁(Sunny) × β₁(Sunny) + α₁(Rainy) × β₁(Rainy)
       = 0.5333 × 0.1824 + 0.1333 × 0.2592
       = 0.09727 + 0.03455
       = 0.1318
```

**Check with other time steps:**
```
At t=2:
α₂(Sunny) × β₂(Sunny) + α₂(Rainy) × β₂(Rainy) = 0.1318 ✓

At t=3:
α₃(Sunny) × β₃(Sunny) + α₃(Rainy) × β₃(Rainy) = 0.1318 ✓
```

**All should be equal!** This verifies correctness of calculations.

## Worked Examples

### Example 1: Weather HMM - Forward Algorithm

**Parameters:**
```
States: Sunny (S), Rainy (R)
Observations: Happy (H), Grumpy (G)

π = {2/3, 1/3}

A = [0.8  0.2]  (Sunny to Sunny, Sunny to Rainy)
    [0.4  0.6]  (Rainy to Sunny, Rainy to Rainy)

B = [0.8  0.2]  (Sunny emits Happy, Grumpy)
    [0.4  0.6]  (Rainy emits Happy, Grumpy)
```

**Observation sequence:** O = {H, G, H}

### Step 1: Initialization (t=1, observation=H)

```
α₁(S) = π_S × b_S(H) = (2/3) × 0.8 = 16/30 = 8/15 ≈ 0.5333
α₁(R) = π_R × b_R(H) = (1/3) × 0.4 = 4/30 = 2/15 ≈ 0.1333
```

### Step 2: First Recursion (t=2, observation=G)

```
α₂(S) = [α₁(S) × a_SS + α₁(R) × a_RS] × b_S(G)
      = [(8/15) × 0.8 + (2/15) × 0.4] × 0.2
      = [(6.4/15) + (0.8/15)] × 0.2
      = (7.2/15) × 0.2
      = 1.44/15
      = 12/125 ≈ 0.096

α₂(R) = [α₁(S) × a_SR + α₁(R) × a_RR] × b_R(G)
      = [(8/15) × 0.2 + (2/15) × 0.6] × 0.6
      = [(1.6/15) + (1.2/15)] × 0.6
      = (2.8/15) × 0.6
      = 1.68/15
      = 14/125 ≈ 0.112
```

### Step 3: Second Recursion (t=3, observation=H)

```
α₃(S) = [α₂(S) × a_SS + α₂(R) × a_RS] × b_S(H)
      = [(12/125) × 0.8 + (14/125) × 0.4] × 0.8
      = [(9.6/125) + (5.6/125)] × 0.8
      = (15.2/125) × 0.8
      = 12.16/125
      = 304/3125 ≈ 0.09728

α₃(R) = [α₂(S) × a_SR + α₂(R) × a_RR] × b_R(H)
      = [(12/125) × 0.2 + (14/125) × 0.6] × 0.4
      = [(2.4/125) + (8.4/125)] × 0.4
      = (10.8/125) × 0.4
      = 4.32/125
      = 108/3125 ≈ 0.03456
```

### Step 4: Termination

```
P(O | λ) = α₃(S) + α₃(R)
         = 304/3125 + 108/3125
         = 412/3125
         ≈ 0.1318
```

**Interpretation:** The probability of observing the sequence {Happy, Grumpy, Happy} given this HMM is approximately **0.1318 or 13.18%**.

### Example 2: Backward Algorithm Verification

Using same HMM and observation sequence as Example 1.

**Initialization (t=3):**
```
β₃(S) = 1
β₃(R) = 1
```

**Step 1: Recursion at t=2 (observation=G)**

```
β₂(S) = a_SS × b_S(H) × β₃(S) + a_SR × b_R(H) × β₃(R)
      = 0.8 × 0.8 × 1 + 0.2 × 0.4 × 1
      = 0.64 + 0.08
      = 0.72

β₂(R) = a_RS × b_S(H) × β₃(S) + a_RR × b_R(H) × β₃(R)
      = 0.4 × 0.8 × 1 + 0.6 × 0.4 × 1
      = 0.32 + 0.24
      = 0.56
```

**Step 2: Recursion at t=1 (observation=H)**

```
β₁(S) = a_SS × b_S(G) × β₂(S) + a_SR × b_R(G) × β₂(R)
      = 0.8 × 0.2 × 0.72 + 0.2 × 0.6 × 0.56
      = 0.1152 + 0.0672
      = 0.1824

β₁(R) = a_RS × b_S(G) × β₂(S) + a_RR × b_R(G) × β₂(R)
      = 0.4 × 0.2 × 0.72 + 0.6 × 0.6 × 0.56
      = 0.0576 + 0.2016
      = 0.2592
```

**Verification using t=1:**
```
P(O|λ) = α₁(S) × β₁(S) + α₁(R) × β₁(R)
       = (8/15) × 0.1824 + (2/15) × 0.2592
       = 0.5333 × 0.1824 + 0.1333 × 0.2592
       = 0.0973 + 0.0346
       = 0.1319 ✓ (matches forward result!)
```

## Key Takeaways

- **Likelihood problem:** Find P(O|λ) for given observation sequence
- **Brute force:** Exponential complexity O(T × N^T) - infeasible
- **Forward algorithm:** Linear complexity O(N² × T) - dynamic programming
- **Backward algorithm:** Alternative linear complexity approach
- **Both algorithms give same result:** Can verify using α × β product
- **Applications:** Model selection, anomaly detection, diagnosis

## 1. Motivation: Why Not Single Perceptrons?

### The Perceptron's Harsh Thresholding Logic

**Problem:** Perceptrons use a **step function** as activation function.

**Example: Movie Rating Prediction**

Given:
- Input: Critics Rating (x₁) ∈ [0, 1]
- Weight: w₁ = 1.0
- Bias: w₀ = -0.5 (threshold θ = 0.5)

**Decision Rule:**
```
y = 1  if w₀ + w₁x₁ ≥ 0
y = 0  if w₀ + w₁x₁ < 0

i.e., y = 1  if -0.5 + x₁ ≥ 0
      y = 1  if x₁ ≥ 0.5
```

**The Problem:**
- Movie with rating 0.51 → Output = 1 (like)
- Movie with rating 0.49 → Output = 0 (dislike)

This is **TOO HARSH!** Such a small difference shouldn't cause completely opposite decisions.

### Mathematical Issue

**Perceptron function characteristics:**
- Sharp transition at threshold
- Not smooth or continuous
- **Not differentiable** at threshold point
- Causes sudden jumps in output

**For real-world applications:**
We expect a **smoother decision function** that gradually changes from 0 to 1.

## 2. Sigmoid Neurons

### The Sigmoid (Logistic) Function

**Solution:** Replace harsh step function with **smooth sigmoid function**.

**Sigmoid Function:**
```
σ(z) = 1 / (1 + e^(-z))
```

where z = w₀ + Σ(i=1 to n) wᵢxᵢ

### Properties of Sigmoid

**Range:** Output ∈ [0, 1]

**Key characteristics:**
- Smooth and continuous everywhere
- Differentiable everywhere (important for gradient descent!)
- S-shaped curve
- Approaches 0 as z → -∞
- Approaches 1 as z → +∞
- σ(0) = 0.5 (midpoint)

### Probability Interpretation

**Critical Insight:** Output range [0, 1] matches **probability range**!

**Sigmoid output can be interpreted as:**
- Probability of belonging to class 1
- Confidence level in prediction
- Soft activation instead of hard threshold

**Example (Movie Liking):**
- σ(-0.5 + 0.49) = σ(-0.01) ≈ 0.49 (49% chance of liking)
- σ(-0.5 + 0.51) = σ(0.01) ≈ 0.51 (51% chance of liking)

Now the difference is **smooth and gradual** instead of harsh!

### Sigmoid Neuron Equation

**Neural computation:**
```
z = w₀ + Σ(i=1 to n) wᵢxᵢ

output = σ(z) = 1 / (1 + e^(-z))
```

**Vectorized form:**
```
output = σ(wᵀx + b)
```

### Why Differentiability Matters

**Perceptron (step function):**
```
y = 1  if z ≥ 0
y = 0  if z < 0

dy/dz = 0 everywhere (except at z=0 where undefined)
```

**Sigmoid function:**
```
σ(z) = 1 / (1 + e^(-z))

dσ/dz = σ(z)(1 - σ(z))  [smooth, well-defined everywhere]
```

The **derivative of sigmoid** is crucial for training via gradient descent!

## 3. Multilayer Networks

### Why Multilayer?

From Lecture 8, we know:
- Single perceptron can only solve linearly separable problems
- Real data is usually not linearly separable
- **Solution:** Multiple layers of neurons

### Network Architecture

**Typical ANN structure:**

```
Input Layer → Hidden Layer(s) → Output Layer
```

### Layer Types

**Input Layer:**
- Where data enters the network
- Number of units = number of input features
- **NO computation** performed here
- Just passes inputs to hidden layers

**Hidden Layer(s):**
- **Core of learning**
- Between input and output layers
- Derives complex relationships between input and output
- Identifies patterns in data
- Can have multiple hidden layers (Deep Neural Network)

**Output Layer:**
- Produces final predictions
- Number of units = number of output classes
- Receives processed information from hidden layers

### Fully Connected Network

**Multi-layer Perceptron (MLP):**
- Each neuron in one layer connected to all neurons in next layer
- Also called **fully connected** network
- Most basic deep learning architecture

### Network Hyperparameters

**Hyperparameters (must be chosen before training):**
1. Number of layers (depth)
2. Number of neurons per layer (width)
3. Activation functions
4. Learning rate
5. Batch size
6. Number of epochs

## 4. Forward Propagation

### Definition

**Forward Propagation:** Process of computing output by moving from input layer through hidden layers to output layer, computing weighted sum and activation at each neuron.

### Weight Matrix Dimensions

**Critical Formula:**
```
Weight Matrix Shape = (# neurons in previous layer) × (# neurons in current layer)
```

**Example:**
```
Layer 1 (Input): 3 neurons
Layer 2 (Hidden): 2 neurons  → Weight matrix W₁ᵗ = 3×2
Layer 3 (Hidden): 5 neurons  → Weight matrix W₂ᵗ = 2×5
Layer 4 (Output): 7 neurons  → Weight matrix W₃ᵗ = 5×7
```

### Forward Pass Computation

**At each neuron:**

```
Step 1: Weighted sum (pre-activation)
  z = Σ(i) wᵢxᵢ + b

Step 2: Apply activation function
  a = σ(z) or f(z) [depending on activation]

Step 3: Pass to next layer
  This activation becomes input to next layer
```

**Vectorized notation:**
```
Z^(l) = W^(l) × A^(l-1) + b^(l)
A^(l) = σ(Z^(l))

where:
  l = layer number
  A^(l) = activations at layer l
  Z^(l) = pre-activations at layer l
```

### Forward Propagation Algorithm

```
1. Initialize weights and biases randomly
2. For layer l = 1 to L:
     a. Compute Z^(l) = W^(l) × A^(l-1) + b^(l)
     b. Compute A^(l) = σ(Z^(l))
3. Return output A^(L)
```

### Worked Example: Forward Pass

**Given Network:**
```
Input Layer:    x₁ = 0.05, x₂ = 0.10
Hidden Layer:   2 neurons, bias = 0.35
Output Layer:   2 neurons, bias = 0.60

Weights (input to hidden):
  w₁₁ = 0.15, w₁₂ = 0.20
  w₂₁ = 0.25, w₂₂ = 0.30

Weights (hidden to output):
  w₃₁ = 0.40, w₃₂ = 0.45
  w₄₁ = 0.50, w₄₂ = 0.55
```

**Forward Pass Calculation:**

```
Step 1: Input to Hidden Layer

Hidden neuron 1:
  z₃ = w₁₁×x₁ + w₂₁×x₂ + b = 0.15(0.05) + 0.25(0.10) + 0.35
     = 0.0075 + 0.025 + 0.35 = 0.3775
  
  a₃ = σ(0.3775) = 1/(1+e^(-0.3775)) ≈ 0.5932

Hidden neuron 2:
  z₄ = w₁₂×x₁ + w₂₂×x₂ + b = 0.20(0.05) + 0.30(0.10) + 0.35
     = 0.01 + 0.03 + 0.35 = 0.39
  
  a₄ = σ(0.39) ≈ 0.5968

Step 2: Hidden to Output Layer

Output neuron 1:
  z₁ = w₃₁×a₃ + w₄₁×a₄ + b = 0.40(0.5932) + 0.50(0.5968) + 0.60
     = 0.2373 + 0.2984 + 0.60 = 1.1357
  
  a₁ = σ(1.1357) ≈ 0.7513

Output neuron 2:
  z₂ = w₃₂×a₃ + w₄₂×a₄ + b = 0.45(0.5932) + 0.55(0.5968) + 0.60
     = 0.2669 + 0.3283 + 0.60 = 1.1952
  
  a₂ = σ(1.1952) ≈ 0.7729

Final Output: [0.7513, 0.7729]
```

## 5. Backward Propagation

### Definition

**Backward Propagation:** Process of modifying parameters (weights, biases) by computing error gradient, propagating error backwards from output layer through hidden layers to input layer.

### Core Idea

1. Compare network's prediction with actual target value
2. Calculate error/loss
3. Compute how much each weight contributed to error
4. Update weights to reduce error
5. Modifications made in "backward" direction (output → hidden → input)

### Why Backward?

**Information flow direction:**
- **Forward:** Input → Hidden → Output (prediction)
- **Backward:** Output error → Hidden error → Input error (corrections)

### Loss Function

**Objective function (to minimize):**

Typical loss functions:
```
1. Mean Squared Error (MSE):
   L = 1/m Σ(predicted - actual)²

2. Cross Entropy Loss (for classification):
   L = -[y·log(ŷ) + (1-y)·log(1-ŷ)]
   
   where y = actual, ŷ = predicted
```

**Why these?**
- MSE for regression tasks
- Cross-entropy for classification tasks
- Both are differentiable (crucial for gradient computation)

### Backward Pass Overview

```
1. Compute output layer error
   δ^(L) = ∇Loss = (prediction - actual)

2. For each layer l = L-1 down to 1:
     a. Compute layer error
        δ^(l) = (W^(l+1))ᵀ δ^(l+1) ⊙ σ'(Z^(l))
     
     b. Compute weight gradients
        ∇W^(l) = δ^(l) × (A^(l-1))ᵀ
     
     c. Compute bias gradients
        ∇b^(l) = δ^(l)

3. Update weights and biases
   W^(l) ← W^(l) - η × ∇W^(l)
   b^(l) ← b^(l) - η × ∇b^(l)
```

## 6. Gradient Descent Optimization

### Background: Taylor Series

**Taylor expansion for 1D function:**
```
f(x + h) ≈ f(x) + h×f'(x) + (h²/2)×f''(x) + ...

For small h, we can approximate:
f(x + h) ≈ f(x) + h×f'(x)
```

**For functions with parameters θ:**
```
f(θ + Δθ) ≈ f(θ) + (Δθ)ᵀ∇f(θ)
```

### Gradient Descent Principle

**Goal:** Minimize loss function L(θ)

**Key insight:** To minimize, we want:
```
L(θ + ηu) - L(θ) < 0

From Taylor series:
(ηu)ᵀ∇L(θ) < 0
u∇L(θ) < 0
```

**Best direction u:**
- Should be opposite to gradient
- u = -∇L(θ) / ||∇L(θ)||

### Gradient Descent Update Rule

**Standard update:**
```
θ_{new} = θ_{old} - η × ∇θ L(θ_{old})
```

**For weights and biases:**
```
w_{t+1} = w_t - η × (∂L/∂w_t)
b_{t+1} = b_t - η × (∂L/∂b_t)
```

where:
- η (eta) = **learning rate** (step size)
- ∇θ L = gradient of loss w.r.t. parameters

### Learning Rate Effects

**Too small learning rate (η << 0.01):**
- Takes tiny steps toward minimum
- Converges very slowly
- Requires many epochs
- May get stuck before reaching minimum

**Too large learning rate (η >> 0.1):**
- Takes huge steps
- May overshoot minimum
- Can diverge (loss increases)
- Never settles at minimum
- Oscillates around or away from minimum

**Optimal learning rate:**
- Balances speed with stability
- Reaches minimum in reasonable time
- Smoothly converges
- Typical range: 0.001 to 0.1

### Gradient Descent Algorithm

```
Algorithm: Gradient Descent

t ← 0
max_iterations ← 1000

While t < max_iterations do:
    Compute gradients: ∇w_t, ∇b_t
    Update weights: w_{t+1} ← w_t - η∇w_t
    Update biases: b_{t+1} ← b_t - η∇b_t
    t ← t + 1
End While
```

### Challenges

**Local Minima Problem:**
```
At local minimum: ∇L = 0
Therefore: w ← w - η(0) = w (no change!)
```

**Issue:** Algorithm stops at local minimum instead of global minimum.

**Solution:** Use techniques like momentum, different initializations, or adaptive learning rates (covered in Lecture 12).

## 7. Worked Examples

### Example 1: Simple Forward Pass

**Network:**
```
Input: x = [0.888, -0.490]
Layer 1 (Hidden): 2 neurons, bias = 0
  w₁ = 1.76, w₂ = 0.40 (neuron 1)
  w₃ = 0.97, w₄ = 2.24 (neuron 2)
```

**Computation:**

```
Neuron 1 (Hidden):
  a₁ = w₁×x₁ + w₂×x₂ + b
     = 1.76(0.888) + 0.40(-0.490)
     = 1.563 - 0.196
     = 1.367

Neuron 2 (Hidden):
  a₂ = w₃×x₁ + w₄×x₂ + b
     = 0.97(0.888) + 2.24(-0.490)
     = 0.862 - 1.098
     = -0.236
```

**After activation:**
```
h₁ = σ(1.367) ≈ 0.796
h₂ = σ(-0.236) ≈ 0.441
```

### Example 2: Computing Gradients

**Given:**
- Predicted output: ŷ = 0.7
- Actual output: y = 0.9
- Loss function: L = (ŷ - y)²

**Gradient computation:**

```
L = (0.7 - 0.9)² = 0.04

∂L/∂ŷ = 2(ŷ - y) = 2(0.7 - 0.9) = -0.4

If ŷ = σ(z):
∂ŷ/∂z = σ(z)(1 - σ(z)) = 0.7 × 0.3 = 0.21

By chain rule:
∂L/∂z = (∂L/∂ŷ)(∂ŷ/∂z) = (-0.4)(0.21) = -0.084
```

## 8. Key Formulas and Summary

### Essential Equations

**Sigmoid function:**
```
σ(z) = 1 / (1 + e^(-z))
σ'(z) = σ(z)(1 - σ(z))
```

**Forward pass:**
```
Z^(l) = W^(l)A^(l-1) + b^(l)
A^(l) = σ(Z^(l))
```

**Loss functions:**
```
MSE: L = (1/m)Σ(ŷ - y)²
Cross-Entropy: L = -[y·log(ŷ) + (1-y)·log(1-ŷ)]
```

**Gradient descent:**
```
θ_{new} = θ_{old} - η·∇θL
```

**Backpropagation:**
```
δ^(L) = ∇L (output error)
δ^(l) = (W^(l+1))ᵀδ^(l+1) ⊙ σ'(Z^(l))
```

### Critical Concepts

| Concept | Definition | Why Important |
|---------|-----------|---------------|
| **Forward Pass** | Computing output from input | Generates predictions |
| **Backward Pass** | Computing error and gradients | Enables weight updates |
| **Learning Rate** | Step size for weight updates | Controls convergence speed |
| **Sigmoid** | Smooth activation function | Enables smooth gradients |
| **Gradient** | Direction of steepest increase | Shows how to minimize loss |
| **Chain Rule** | Derivative composition rule | Enables gradient computation |

### Connections

```
Perceptron (L7) → Sigmoid Neurons (L9) → Deep Networks (L10+)

Step function       Smooth sigmoid          Multiple layers
(harsh)             (smooth gradients)      (universal approximation)
```

## 1. Why Activation Functions?

### Without Activation Functions: Linear Problem

**Observation:** Consider a neural network WITHOUT activation functions.

```
Layer 1: z₁ = W₁x + b₁
Layer 2: z₂ = W₂z₁ + b₂
Layer 3: z₃ = W₃z₂ + b₃

Simplifying:
z₃ = W₃(W₂(W₁x + b₁) + b₂) + b₃
   = W₃W₂W₁x + (W₃W₂b₁ + W₃b₂ + b₃)
   = Wx + b    [where W = W₃W₂W₁]
```

**Key insight:** Multiple linear transformations compose to form a single linear transformation!

### Why This Is A Problem

**Without activation functions:**
- Deep network = single linear regression model
- Cannot learn non-linear patterns
- Cannot approximate non-linear functions
- All layers are redundant (could replace with single layer)
- **Network lacks expressiveness**

### The Solution: Non-Linear Activation Functions

**Activation function:** Non-linear transformation applied to neuron's input before propagating to next layer.

**Effect:**
```
Layer l:  
  z^(l) = W^(l)a^(l-1) + b^(l)        [linear combination]
  a^(l) = f(z^(l))                    [non-linear activation]
```

**Result:**
- Each layer can learn non-linear transformations
- Composition of non-linear functions = complex non-linear function
- Network becomes universal function approximator

## 2. Sigmoid Function

### Definition

**Sigmoid (Logistic) Function:**
```
σ(z) = 1 / (1 + e^(-z))
```

### Properties

**Range:** [0, 1]

**Key characteristics:**
- **Smooth:** Continuous everywhere
- **Differentiable:** σ'(z) = σ(z)(1 - σ(z))
- **S-shaped:** Gradual transition
- **Centered at 0.5:** σ(0) = 0.5
- **Monotonically increasing:** As z increases, σ(z) increases

### Graph

```
σ(z)
  1.0 |                      ___---
      |                  _---
  0.8 |              _--
      |           _-
  0.6 |        _-
      |      |-
  0.4 |    _-
      |   /
  0.2 |  /
      | /
  0.0 |/____________________________ z
     -8  -4   0   4   8
```

### Advantages

1. **Probability interpretation:** Output ∈ [0,1] matches probability range
2. **Smooth gradients:** Differentiable everywhere, enables gradient descent
3. **Non-linear:** Single sigmoid neuron can form decision boundaries
4. **Historical:** Well-studied, widely used

### Disadvantages

1. **Vanishing gradients:** For large |z|, σ'(z) ≈ 0 (gradients become very small)
2. **Slow training:** Small gradients mean slow weight updates
3. **Not zero-centered:** Output always positive, can cause zigzagging gradient updates
4. **Computationally expensive:** Involves exponential calculation

### When to Use

- **Binary classification** problems
- **Output layer** of classification networks
- **Single hidden layer** networks (older approach)

## 3. Tanh (Hyperbolic Tangent)

### Definition

**Tanh Function:**
```
tanh(z) = (e^(2z) - 1) / (e^(2z) + 1)
        = (1 - e^(-2z)) / (1 + e^(-2z))
        = 2σ(2z) - 1
```

### Properties

**Range:** [-1, 1]

**Key characteristics:**
- **Smooth:** Continuous everywhere
- **Differentiable:** tanh'(z) = 1 - tanh²(z)
- **S-shaped:** Similar to sigmoid but on [-1, 1]
- **Zero-centered:** tanh(0) = 0 (output centered at 0)
- **Antisymmetric:** tanh(-z) = -tanh(z)

### Graph

```
tanh(z)
   1.0 |                      ___---
       |                  _---
   0.5 |              _--
       |           _-
   0.0 |__________|___________ 
       |      _-       z
  -0.5 |    _-
       |   /
  -1.0 |--/____________________
      -8  -4   0   4   8
```

### Comparison with Sigmoid

**Advantages of tanh over sigmoid:**
1. **Zero-centered:** Output range [-1, 1] centered at 0
   - Negative inputs strongly mapped negative
   - Zero inputs mapped near zero
   - Positive inputs strongly mapped positive
2. **Larger gradient:** tanh'(z) ranges up to 1 (vs sigmoid max 0.25)
3. **Faster training:** Larger gradients enable faster learning
4. **Better for hidden layers:** Generally works better than sigmoid

**Disadvantage:** Still suffers from vanishing gradients for large |z|

### When to Use

- **Hidden layers** (generally better than sigmoid)
- **Recurrent Neural Networks (RNNs)**
- **Any problem where zero-centered activation helps**

## 4. ReLU (Rectified Linear Unit)

### Definition

**ReLU Function:**
```
f(x) = max(0, x)

More formally:
f(x) = x      if x > 0
       0      if x ≤ 0
```

### Properties

**Range:** [0, ∞)

**Key characteristics:**
- **Simple:** Easiest activation to compute
- **Piecewise linear:** Two linear pieces
- **Differentiable almost everywhere:**
  ```
  f'(x) = 1    if x > 0
          0    if x < 0
          (undefined at x = 0, but often set to 0 or 1)
  ```
- **Computational efficiency:** Just max(0, x)
- **No exponential calculation:** Much faster than sigmoid/tanh

### Graph

```
f(x)
   5 |         /
     |        /
   3 |       /
     |      /
   1 |     /
     |    /
   0 |___/________________
     | /
  -2 |___________________ x
    -4  -2   0   2   4
```

### Advantages

1. **Computational efficiency:** O(1) operation
2. **No vanishing gradients:** f'(x) = 1 for x > 0
3. **Sparse activation:** Only ~50% neurons active (set to 0)
4. **Faster convergence:** Training is much faster
5. **Biologically plausible:** Similar to biological neuron firing

### Disadvantages

1. **Dead ReLU problem:** Neurons can "die"
   - When a neuron always outputs 0
   - Gradient is 0, no updates occur
   - Neuron becomes inactive permanently
2. **Not differentiable at 0:** (minor issue in practice)
3. **Unbounded:** No upper limit on output
4. **Not smooth:** Non-differentiable at x = 0

### The Dying ReLU Problem

**What happens:**
- Neuron receives negative input: z < 0
- ReLU outputs: f(z) = 0
- Gradient: f'(z) = 0
- Weight update: w ← w - η(0) (no change)
- Neuron never recovers (dies)

**Consequence:**
- Large portion of network become inactive
- Network loses expressive power
- Training stalls

### When to Use

- **Hidden layers** (most common choice)
- **Deep neural networks** (standard practice)
- **CNNs** (convolutional neural networks)
- **Computer vision** tasks
- **Generally:** Default choice for hidden layers unless proven otherwise

## 5. Leaky ReLU

### Definition

**Leaky ReLU Function:**
```
f(x) = x         if x > 0
       αx        if x ≤ 0

where α is a small positive constant (typically 0.01)
```

### Properties

**Range:** (-∞, ∞)

**Key characteristics:**
- **Small slope for negatives:** Instead of 0, use αx (α << 1)
- **Fixes dying ReLU:** Negative values have non-zero gradient
- **Preserves non-linearity:** Still non-linear
- **Learnable:** Can make α learnable (Parametric ReLU)

### Graph

```
f(x)
   5 |         /
     |        /
   3 |       /
     |      /
   1 |     /
     |    /
   0 |___/________________
     | /
  -2 |/_________________ x  (small positive slope)
    -4  -2   0   2   4
```

### Comparison: ReLU vs Leaky ReLU

**ReLU:**
```
x = 2:   f(2) = 2,    f'(2) = 1
x = -2:  f(-2) = 0,   f'(-2) = 0     ← Problem: zero gradient
```

**Leaky ReLU (α = 0.01):**
```
x = 2:   f(2) = 2,      f'(2) = 1
x = -2:  f(-2) = -0.02, f'(-2) = 0.01  ← Fix: non-zero gradient
```

### Parametric ReLU (PReLU)

**Idea:** Instead of fixed α, learn the slope!

**Function:**
```
f(x) = x          if x > 0
       α(x)·x     if x ≤ 0

where α(x) is learned during training
```

**Advantage:** Network learns optimal slope for negatives

### When to Use

- **When ReLU produces dead neurons**
- **When training is stalling**
- **Before switching to other architectures**
- **As default for problematic networks**

## 6. Softmax Function

### Definition

**Softmax Function (Multi-class Sigmoid):**

For output layer with K classes:

```
σⱼ(z) = e^(zⱼ) / Σ(k=1 to K) e^(zₖ)

where j = 1 to K (each output neuron)
```

### Properties

**Range:** [0, 1] for each output

**Key characteristics:**
- **Probabilistic:** Outputs sum to 1 (valid probability distribution)
- **Generalization:** Sigmoid for binary (K=2) becomes softmax
- **Max emphasizing:** Largest z gets highest probability
- **Normalized:** Always produces valid probability distribution

### Mathematical Properties

**Sum property:**
```
Σ(j=1 to K) σⱼ(z) = 1

This makes softmax a probability distribution!
```

**Derivative:**
```
∂σⱼ/∂zᵢ = σⱼ(δⱼᵢ - σᵢ)

where δⱼᵢ = 1 if j=i, 0 otherwise (Kronecker delta)
```

### Example

**Given output layer pre-activations:**
```
z = [2.0, 1.0, 0.1]

Softmax calculation:
e^2.0 = 7.39
e^1.0 = 2.72
e^0.1 = 1.10

Sum = 11.21

σ₁ = 7.39/11.21 = 0.659 (65.9%)
σ₂ = 2.72/11.21 = 0.243 (24.3%)
σ₃ = 1.10/11.21 = 0.098 (9.8%)

Verification: 0.659 + 0.243 + 0.098 = 1.0 ✓
```

### Interpretation

**Output is probability distribution over K classes:**
- 65.9% chance of class 1
- 24.3% chance of class 2
- 9.8% chance of class 3

**Decision:** Argmax of softmax
```
Predicted class = argmax(σⱼ) = class 1 (highest probability)
```

### When to Use

- **Multi-class classification** (must use in output layer)
- **Any problem with K > 2 classes**
- **When outputs need probability interpretation**
- **Standard for classification networks**

## 7. Choosing Activation Functions

### Guidelines

**Output Layer:**
```
Binary Classification:
  → Sigmoid or Tanh

Multi-class Classification:
  → Softmax (REQUIRED)

Regression:
  → Linear (no activation) or ReLU
```

**Hidden Layers:**
```
Default choice:
  → ReLU (fast, simple, effective)

If ReLU causes dead neurons:
  → Leaky ReLU or PReLU

For special architectures:
  → Tanh for RNNs
  → ReLU for CNNs and feedforward networks
```

### Decision Checklist

Before choosing activation:
- [ ] **Differentiability:** Is it differentiable? (needed for backprop)
- [ ] **Computational cost:** How expensive to compute?
- [ ] **Convergence speed:** Does network train quickly?
- [ ] **Vanishing gradient:** Does gradient vanish for extreme values?
- [ ] **Smoothness:** Is function smooth or piecewise?
- [ ] **Problem type:** Classification vs Regression?
- [ ] **Network depth:** Shallow vs Deep?

### Universal Approximation Theorem

**Requirement:** Network must have non-linear activation functions.

**Key activation properties:**
1. **Non-linearity:** f(ax + by) ≠ af(x) + bf(y)
2. **Boundedness (for some):** Output range should be bounded
3. **Continuity:** Function should be continuous
4. **Non-constant:** Not f(x) = c for all x

**All discussed functions satisfy these!**

## 8. Practice Problems

### Problem 1: Sigmoid vs Tanh

**Question:** Why is tanh better than sigmoid for hidden layers?

**Answer:**
1. **Zero-centered:** tanh output ∈ [-1, 1] vs sigmoid [0, 1]
   - Zero-centered reduces zigzagging during optimization
   - Gradient updates more stable
2. **Larger gradient:** tanh'(z) max is 1 vs sigmoid max 0.25
   - Stronger gradients
   - Faster training
3. **Better convergence:** Zero-centered helps optimization
4. **Historical:** Networks with tanh hidden layers train faster

---

### Problem 2: ReLU vs Sigmoid

**Network with 1000 hidden neurons using:**
- **Sigmoid:** Trains for 100 epochs, loss still decreasing
- **ReLU:** Trains for 10 epochs, loss converged

**Why?**

```
Sigmoid:
  • Vanishing gradients: σ'(z) ≈ 0 for |z| large
  • For z = 5: σ'(5) ≈ 0.007 (very small)
  • Slow weight updates
  • Training much slower

ReLU:
  • f'(x) = 1 for x > 0
  • Constant gradient (no vanishing)
  • Fast weight updates
  • Training much faster
```

---

### Problem 3: Dead ReLU Problem

**Network has 1000 neurons in hidden layer:**
- After 10 epochs, 800 neurons have dead ReLU (always output 0)
- Network stops learning

**Solution?**

```
Options:
1. Switch to Leaky ReLU (α = 0.01)
   • Neurons have f'(z) = α for z < 0
   • Never completely die
   
2. Lower learning rate
   • Large α causes weight swings
   • Can kill neurons
   • Smaller α prevents extreme values
   
3. Use batch normalization
   • Keeps neuron inputs in healthy range
   • Prevents extreme positive/negative values
   
4. Switch to PReLU
   • Learn optimal α for each neuron
```

### Problem 4: Softmax Computation

**Given 3 output neurons with pre-activations:**
```
z₁ = 3.0
z₂ = 1.0
z₃ = 2.0
```

**Compute softmax probabilities:**

```
Step 1: Exponentiate
e^3.0 = 20.09
e^1.0 = 2.72
e^2.0 = 7.39
Sum = 30.20

Step 2: Normalize
σ₁ = 20.09/30.20 = 0.665
σ₂ = 2.72/30.20 = 0.090
σ₃ = 7.39/30.20 = 0.245

Result: [0.665, 0.090, 0.245]
Predicted class: 1 (highest probability)
```

## 9. Summary

### Activation Functions Comparison

| Function | Range | Gradient | Use Case | Pros | Cons |
|----------|-------|----------|----------|------|------|
| **Sigmoid** | [0,1] | 0.25 max | Output (binary) | Smooth, interpretable | Vanishes, slow |
| **Tanh** | [-1,1] | 1 max | Hidden layers | Better than sigmoid | Still vanishes |
| **ReLU** | [0,∞) | 1 constant | Hidden layers | Fast, simple | Dies, unbounded |
| **Leaky ReLU** | [-∞,∞) | α or 1 | When ReLU dies | Fixes dying | Slightly slower |
| **Softmax** | [0,1] | Varies | Output (multi-class) | Probability dist | Only for output |

### Key Takeaways

1. **Activation functions enable non-linearity** → Networks can learn complex patterns
2. **Without activations** → Multiple layers become one linear transformation
3. **Sigmoid/Tanh:** Classic choices, suffer from vanishing gradients
4. **ReLU:** Modern default, fast and effective, watch for dying neurons
5. **Softmax:** Required for multi-class classification output layer
6. **Choice matters:** Wrong activation can kill training performance
7. **Layer-specific:** Different layers may need different activations

### Practical Rule of Thumb

```
Hidden layers: Try ReLU first
  ↓ If network trains slowly or neurons die
  ↓ Switch to Leaky ReLU
  ↓ If still problematic
  ↓ Use Tanh or experiment with other options

Output layer:
  Binary classification → Sigmoid
  Multi-class → Softmax
  Regression → Linear (no activation)
```

## 1. Introduction

### What is SVM?

**Support Vector Machine (SVM)** is a powerful supervised learning algorithm used for:
- **Classification** (primary focus here)
- **Regression**

### Applications

**SVM can handle:**
1. **Linear classification** - Linearly separable data
2. **Non-linear classification** - Via kernel trick
3. **Binary classification** (focus here)
4. **Multi-class classification** - Using One-vs-All strategy

---

## 2. Rough Idea of SVM

### Core Concept

**SVM works as a linear classifier by default.**

**Definition:** A dataset is said to be **linearly separable** if we can have a hyperplane that separates the data into required number of classes.

### Hyperplane Dimensions

```
2 Dimensions: Line separates the data
3 Dimensions: Plane separates the data
d Dimensions: (d-1) dimensional hyperplane separates data
```

**Example:** In d=5 dimensions, separator is a 4-dimensional hyperplane (not visualizable!)

### Input Space

```
Input vector: X ∈ ℝᵈ
where d = number of features describing an instance
```

## 3. History and Motivation

### Vapnik's Contribution

- **Timeline:** Vapnik thought about SVM in early 1960s, implemented in 1990s
- **Application:** Handwritten digit recognition at Bell Labs
- **Impact:** Revolutionary approach to machine learning

### The Core Question

**"How do we separate these points?"**

**Answer:** "By drawing a straight line..."

**But WHICH LINE?**

There are **infinitely many lines** that can separate the classes. How do we choose the **optimal one**?

### SVM Philosophy

```
         Positive examples (+1)
         ╱
        ╱  Widest Street
       ╱    (Maximum Margin)
      ─────────────────────
       ╲
        ╲
         Negative examples (-1)
```

**Key Idea:** SVM puts the decision boundary such that the street (margin) separating positive from negative examples is as wide as possible.

## 4. Optimal Hyperplane Concept

### Which Points Should Influence Optimality?

**Different algorithms use different strategies:**

| Algorithm | Strategy | Result |
|-----------|----------|--------|
| Linear Regression | All points matter | Can be influenced by outliers |
| Neural Networks | All points matter | Training focused on all examples |
| **SVM** | Only "difficult" points near boundary | Robust, focuses on decision boundary |

**Support Vector Machines:** Focus only on difficult points close to the decision boundary.

### Finding the Optimal Hyperplane

**Approach:** This is an **optimization problem** solved using:
- **Lagrange multipliers** (analytic solution)
- **Quadratic programming** (algorithmic solution)

## 5. Hyperplane Equations

### Three Parallel Hyperplanes

```
                    WT·X + b = +1
                    
                    WT·X + b = 0  (Decision Boundary)
                    
                    WT·X + b = -1
```

**Properties:**
- All three hyperplanes are parallel
- They have the same normal vector W
- Only b (bias) differs

### General Hyperplane Equation

```
WᵀX + b = 0

where:
  W = weight vector (normal to hyperplane)
  X = input feature vector
  b = bias term
```

### Decision Rule for Hyperplanes

**For the decision boundary WᵀX + b = 0:**

```
If WᵀX + b ≥ 0  →  X is classified as positive (+1)
If WᵀX + b < 0  →  X is classified as negative (-1)
```

---

## 6. Decision Rules

### Boundary Hyperplanes

**Lower hyperplane (for negative class):**
```
WᵀX⁻ + b₁ ≤ 0  →  X⁻ is negative
```

**Upper hyperplane (for positive class):**
```
WᵀX⁺ + b₂ ≥ 0  →  X⁺ is positive
```

### Alternative Representation

**We can also write as:**
```
For negative points: WᵀX + b ≤ -1
For positive points: WᵀX + b ≥ +1
```

### Unified Notation

**Define:** 
```
yᵢ = +1  for positive samples
yᵢ = -1  for negative samples
```

**Then we can write single constraint:**
```
yᵢ(WᵀXᵢ + b) ≥ 1
```

**Equivalently:**
```
yᵢ(WᵀXᵢ + b) - 1 ≥ 0
```

### Proof of Equivalence

**Given:**
- WᵀX⁻ + b₁ ≤ 0 and WᵀX⁺ + b₂ ≥ 0

**Define:**
```
C = (b₁ + b₂) / 2
D = (b₂ - b₁) / 2

Then:
b₁ = C - D
b₂ = C + D
```

**Substituting:**
```
WᵀX + (C - D) ≤ 0  →  WᵀX + C ≤ D
WᵀX + (C + D) ≥ 0  →  WᵀX + C ≥ -D
```

**Dividing by D:**
```
WᵀX/D + C/D ≤ 1  →  WᵀX + b ≤ -1
WᵀX/D + C/D ≥ -1  →  WᵀX + b ≥ 1
```

**Let W̃ = W/D and b̃ = C/D, then:**
```
yᵢ(W̃ᵀXᵢ + b̃) ≥ 1
```

## 7. Margin Calculation

### Intuition: The "Gutter"

```
Support vectors on upper boundary: WᵀX + b = +1
                        ↑
                        | margin
                        ↓
Support vectors on lower boundary: WᵀX + b = -1
```

### Calculating Width

**Step 1:** Take a positive point X⁺ on the boundary WᵀX + b = 1

**Step 2:** Project it onto the weight vector W

```
Unit vector: ŵ = W / ||W||
Projection length: ||Projection(X⁺)|| = (ŵ · X⁺) = (WᵀX⁺) / ||W||
```

**Step 3:** Take a negative point X⁻ on the boundary WᵀX + b = -1

**Step 4:** Project it similarly

```
||Projection(X⁻)|| = (WᵀX⁻) / ||W||
```

### Width Formula

**From constraints:**
```
WᵀX⁺ + b = 1   →   WᵀX⁺ = 1 - b
WᵀX⁻ + b = -1  →   WᵀX⁻ = -1 - b
```

**Width of margin:**
```
width = ||Projection(X⁺)|| - ||Projection(X⁻)||
      = (WᵀX⁺) / ||W|| - (WᵀX⁻) / ||W||
      = [(1 - b) - (-1 - b)] / ||W||
      = [1 - b + 1 + b] / ||W||
      = 2 / ||W||
```

**Therefore:**
```
Margin width = 2 / ||W||
```

**Key Insight:** To maximize margin, we minimize ||W|| (or equivalently ||W||²)

---

## 8. Primal Problem Formulation

### Objective Function

**Goal:** Maximize margin = Maximize 2/||W||

**Equivalently:** Minimize ||W|| or Minimize (1/2)||W||²

**Why (1/2)?** For mathematical convenience in calculus

### The Primal SVM Problem

```
Minimize: (1/2) ||W||²

Subject to: yᵢ(WᵀXᵢ + b) ≥ 1  for i = 1 to m

where:
  m = number of training instances
  yᵢ ∈ {+1, -1}
  W ∈ ℝᵈ
```

### Problem Properties

**This is a standard constrained optimization problem:**

| Property | Value |
|----------|-------|
| Objective | Quadratic (||W||²) |
| Constraints | Linear (yᵢ(WᵀXᵢ + b) ≥ 1) |
| Type | Convex optimization |
| Solvability | ✓ Standard problem (QP) |

**Solution Method:** Can be solved using:
1. Quadratic programming (QP) software
2. **Lagrangian duality (preferred)**

---

## 9. Lagrange Multipliers

### Motivation

We want to solve a **constrained optimization problem** with **inequality constraints**.

**Method:** Transform into **unconstrained** problem using Lagrange multipliers.

### Lagrangian Function

**For the SVM primal problem:**

```
L(W, b, α) = (1/2)||W||² - Σᵢ₌₁ᵐ αᵢ[yᵢ(WᵀXᵢ + b) - 1]

where:
  αᵢ = Lagrange multiplier for constraint i
  αᵢ ≥ 0 (non-negativity constraint)
```

### Geometric Intuition

**Why Lagrange multipliers work:**

1. At optimal point X*, gradients of objective and constraint must be aligned
2. **∇g(X)** is orthogonal to constraint surface g(X) = 0
3. **∇f(X*)** must also be orthogonal to surface (else we could increase f by moving along surface)
4. Therefore: **∇f(X*) = λ∇g(X*)** for some scalar λ

### Example 1: Simple Optimization

**Problem:**
```
Maximize: f(X) = 1 - x₁² - x₂²
Subject to: g(X) = x₁ + x₂ - 1 = 0
```

**Lagrangian:**
```
L(X, λ) = f(X) - λg(X)
        = 1 - x₁² - x₂² - λ(x₁ + x₂ - 1)
```

**First-order conditions:**
```
∂L/∂x₁ = -2x₁ - λ = 0
∂L/∂x₂ = -2x₂ - λ = 0
∂L/∂λ = -(x₁ + x₂ - 1) = 0
```

**Solution:**
```
x₁ = 1/2
x₂ = 1/2
λ = -1
f(X*) = 1/2
```

### Example 2: Product Maximization

**Problem:**
```
Maximize: f(x₁, x₂) = x₁·x₂
Subject to: h(x₁, x₂) = x₁ + 4x₂ - 16 = 0
```

**Lagrangian:**
```
L(x₁, x₂, λ) = x₁·x₂ - λ(x₁ + 4x₂ - 16)
```

**First-order conditions:**
```
∂L/∂x₁ = x₂ - λ = 0
∂L/∂x₂ = x₁ - 4λ = 0
∂L/∂λ = x₁ + 4x₂ - 16 = 0
```

**Solution:**
```
From first two equations: x₁ = 4x₂
Substitute into constraint: 4x₂ + 4x₂ = 16  →  x₂ = 2
Therefore: x₁ = 8, λ = 2
Maximum value: f(8, 2) = 16
```

### Handling Multiple Constraints

**For multiple equality constraints:**
```
L(X, λ) = f(X) - λ₁g₁(X) - λ₂g₂(X) - ... - λₖgₖ(X)

(One Lagrange multiplier for each constraint)
```

### Inequality Constraints - KKT Conditions

**For inequality constraints g(X) ≥ 0:**

**Karush-Kuhn-Tucker (KKT) conditions:**
```
g(X) ≥ 0              (Primal feasibility)
λ ≥ 0                 (Dual feasibility)
λ·g(X) = 0            (Complementary slackness)
```

**Interpretation:**
- If constraint is **active** (g(X) = 0): λ can be > 0
- If constraint is **inactive** (g(X) > 0): λ must be = 0
- Complementary slackness: Either λ = 0 OR g(X) = 0 (or both)

## 10. Dual Problem

### Derivation

**Starting from Lagrangian:**
```
L(W, b, α) = (1/2)||W||² - Σᵢ₌₁ᵐ αᵢ[yᵢ(WᵀXᵢ + b) - 1]
```

**Set partial derivatives to zero:**

**For W:**
```
∂L/∂W = W - Σᵢ₌₁ᵐ αᵢyᵢXᵢ = 0

Therefore: W = Σᵢ₌₁ᵐ αᵢyᵢXᵢ
```

**For b:**
```
∂L/∂b = - Σᵢ₌₁ᵐ αᵢyᵢ = 0

Therefore: Σᵢ₌₁ᵐ αᵢyᵢ = 0
```

### Dual Optimization Problem

**After substituting back into Lagrangian:**

```
Maximize: W(α) = Σᵢ₌₁ᵐ αᵢ - (1/2) Σᵢ₌₁ᵐ Σⱼ₌₁ᵐ αᵢαⱼyᵢyⱼ(Xᵢ·Xⱼ)

Subject to:
  C1: αᵢ ≥ 0           for all i = 1 to m
  C2: Σᵢ₌₁ᵐ αᵢyᵢ = 0
```

### Why Solve Dual Instead of Primal?

**Advantages:**
1. **Computational efficiency** - Dual often faster, especially when d >> m
2. **Kernel trick** - Dot products can be replaced with kernel functions
3. **Sparsity** - Most αᵢ = 0, only support vectors have αᵢ > 0
4. **Theoretical elegance** - Reveals structure of solution

### Sparsity of Solution

**Key observation:**
```
W = Σᵢ₌₁ᵐ αᵢyᵢXᵢ
```

**Only training points with αᵢ > 0 contribute to W!**

**These special points are called SUPPORT VECTORS.**

---

## 11. Support Vectors

### Definition

**Support vectors** are training points whose Lagrange multiplier αᵢ > 0.

**These are the "difficult" points** that determine the decision boundary.

### Complementary Slackness

**From KKT conditions:**
```
αᵢ[yᵢ(WᵀXᵢ + b) - 1] = 0

for all i = 1 to m
```

**This means:**
```
Either αᵢ = 0  OR  yᵢ(WᵀXᵢ + b) - 1 = 0
```

### Two Cases

**Case 1:** Non-support vectors (αᵢ = 0)
- Point is correctly classified and far from margin
- Does NOT affect W
- Would NOT change boundary if deleted

**Case 2:** Support vectors (αᵢ > 0)
- Point lies ON the margin boundary
- yᵢ(WᵀXᵢ + b) = 1
- DOES affect W
- WOULD change boundary if deleted

### Support Vector Guidelines

**Guideline 1:** A point is a support vector if:
- Imagine deleting it
- If you would draw a different SVM boundary → It's a support vector
- If boundary stays same → It's NOT a support vector

**Guideline 2:** 
- Only points on the gutter/margin can be support vectors
- Non-margin points CANNOT be support vectors

**Guideline 3:** 
- αᵢ measures "supportiveness" of point i
- Support vectors far from boundary have LOWER αᵢ
- Support vectors close to boundary have HIGHER αᵢ

### Finding Support Vectors

**After solving dual problem:**
1. Some αᵢ > 0 (support vectors)
2. Most αᵢ = 0 (non-support vectors)
3. From complementary slackness: αᵢ > 0 ⟹ yᵢ(WᵀXᵢ + b) = 1

## 12. Classification of New Points

### Classification Rule

**Given a new point U with known optimal W and b:**

```
If WᵀU + b ≥ +1  →  U is predicted POSITIVE with HIGH confidence
If WᵀU + b ≤ -1  →  U is predicted NEGATIVE with HIGH confidence
If -1 < WᵀU + b < +1  →  U is in margin (LOW confidence) - SOFT MARGIN needed
```

### Decision Boundary

```
WᵀU + b = 0  →  Decision boundary
WᵀU + b = +1  →  Positive support vectors
WᵀU + b = -1  →  Negative support vectors
```

### Computing Classification

**Efficient computation using support vectors:**

```
W = Σᵢ αᵢyᵢXᵢ

Therefore:
WᵀU = (Σᵢ αᵢyᵢXᵢ)ᵀU
    = Σᵢ αᵢyᵢ(Xᵢ·U)

The prediction for U is:
sign(Σᵢ αᵢyᵢ(Xᵢ·U) + b)
```

**Key advantage:** Only need to compute dot products with support vectors!

## 📊 Key Formulas Reference

**Margin:** width = 2/||W||

**Primal Problem:**
```
min (1/2)||W||²
s.t. yᵢ(WᵀXᵢ + b) ≥ 1
```

**Lagrangian:**
```
L(W,b,α) = (1/2)||W||² - Σᵢ αᵢ[yᵢ(WᵀXᵢ + b) - 1]
```

**Optimal W:**
```
W* = Σᵢ αᵢ*yᵢXᵢ
```

**Dual Problem:**
```
max W(α) = Σᵢ αᵢ - (1/2)Σᵢ Σⱼ αᵢαⱼyᵢyⱼ(Xᵢ·Xⱼ)
s.t. αᵢ ≥ 0 and Σᵢ αᵢyᵢ = 0
```

**Classification:**
```
sign(WᵀU + b) = sign(Σᵢ αᵢyᵢ(Xᵢ·U) + b)
```

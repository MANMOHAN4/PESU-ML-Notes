## 1. Introduction to Random Forest

### What is Random Forest?

**Random Forest** = Ensemble classifier using **many decision tree models**

**Characteristics:**
- Uses multiple decision trees (not just one)
- Trees trained on different data subsets
- Can be used for **Classification** or **Regression**
- Provides **accuracy** and **variable importance** information

### Key Difference

```
Decision Tree: ONE tree
└─ Makes single prediction path

Random Forest: MANY trees (usually 100+)
├─ Each tree makes prediction
├─ Aggregate all predictions
└─ Final = Majority vote (classification) or average (regression)
```

### Why Not Just Use One Big Decision Tree?

**One tree problems:**
- ✗ Prone to overfitting (memorizes training data)
- ✗ High variance (small changes in data → big tree changes)
- ✗ Sensitive to outliers
- ✗ May find local optima

**Many trees solution:**
- ✓ Different perspectives on same problem
- ✓ Averaging reduces variance significantly
- ✓ Robust to outliers (isolated errors vote is minimal)
- ✓ Better generalization

## 2. Relationship to Decision Trees

### Decision Tree Refresher

**Single decision tree:**
- Recursive splitting on features
- Minimizes impurity (entropy/Gini)
- Builds one deterministic model
- Can overfit easily

### Random Forest as Extension

**Random Forest:**
- Combines bagging with decision trees
- Adds randomness in **data selection**
- Adds randomness in **feature selection**
- Many trees achieve robustness

### Visual Intuition

```
Decision Tree Prediction Path:
  Input → Branch 1 → Branch 2 → Leaf → Output
  
Random Forest Prediction:
  Input → Tree 1 → Output₁
       → Tree 2 → Output₂
       → Tree 3 → Output₃
       ...
       → Tree N → OutputN
  
  Final = Majority vote(Output₁, Output₂, ..., OutputN)
```

## 3. Bootstrap Aggregating (Bagging)

### What is Bootstrapping?

**Bootstrap sample** = Sample created by:
- Sampling from original dataset **with replacement**
- Typically same size as original
- Some records appear multiple times, some don't appear

### Bootstrapping Statistics

**Mathematical fact:**
```
P(record x NOT selected in bootstrap sample) = (1 - 1/n)ⁿ ≈ 1/e

where n = number of records in original dataset

For large n: 1/e ≈ 0.368 or 36.8%
```

**Interpretation:**
```
Original dataset: 100 records
├─ Bootstrap sample: Contains ~63 unique records
├─ Duplicates included: ~37 records appear multiple times
└─ Not selected: ~37 records excluded from this bootstrap
```

### Why This Matters

```
Different bootstrap samples:
├─ Tree 1 trained on bootstrap₁ (different records)
├─ Tree 2 trained on bootstrap₂ (different records)
├─ Tree 3 trained on bootstrap₃ (different records)
└─ Different data → Different trees → Diversity achieved!
```

## 4. Out-of-Bag (OOB) Error

### What is OOB?

**Out-of-Bag (OOB) set** = Records NOT selected for a particular bootstrap sample

**Key insight:** ~37% of records are OOB for each tree

**Advantage:** Can use OOB records as natural test set!

### Why OOB is Useful

**Normal cross-validation:**
- Need separate test set (wastes data)
- More computational overhead

**OOB approach:**
- Uses existing unselected records
- No data wastage
- Free validation set!

### Calculating OOB Error

**Steps:**
1. For each record in original dataset
2. Find all trees where this record was OOB (not in training)
3. Get predictions from only those OOB trees
4. Take majority vote of these OOB trees
5. Compare to actual label

**Aggregate:**
```
OOB Error = (# incorrect OOB predictions) / (total records)
```

### OOB Error Advantages

```
✓ No separate validation needed
✓ Unbiased estimate of test error
✓ Uses all data for training
✓ Computationally efficient
✓ Good proxy for test set performance
```

## 5. Random Forest Algorithm

### Step-by-Step Algorithm

**Step 1: Create Bootstrap Samples**
```
For each of T trees (T ≈ 100):
├─ Create bootstrap sample from original dataset
└─ Sample with replacement, same size as original
```

**Step 2: For Each Bootstrap Sample**
```
Build decision tree:
├─ Randomly select R features (where R < M total features)
├─ From these R features, find best split
├─ Split recursively for each node
├─ Continue until termination condition
└─ No pruning needed
```

**Step 3: Create Predictions**
```
For new data point:
├─ Run through all T trees
├─ Each tree gives prediction
├─ Classification: Majority vote
├─ Regression: Average predictions
└─ Output: Final prediction
```

## 6. Random Feature Selection

### Why Random Feature Selection?

**Reason:** If one feature is very strong:
- All trees would pick same feature at root
- Trees become very similar
- No diversity achieved
- Ensemble loses advantage

### How It Works

**Given:**
- M = total features in dataset
- R = random features to consider per tree (R < M)

**For each split:**
1. Randomly select R features
2. Among these R, find best split
3. Use that split

**Typical values:**
```
Classification: R = √M
Regression: R = M/3
```

### Effect on Diversity

```
All features considered:
├─ Tree 1, Tree 2, Tree 3 all use Feature 1 at root
├─ Very similar trees
└─ No diversity → No ensemble benefit

Random features (R < M):
├─ Tree 1 uses Feature 3 at root
├─ Tree 2 uses Feature 5 at root
├─ Tree 3 uses Feature 1 at root
├─ Different trees → Different perspectives
└─ Diversity achieved!
```

## 7. How Random Forest Works

### Complete Random Forest Process

```
Original Dataset
├─ 100 records, 10 features
│
├─ Bootstrap₁ → Tree₁ (features: F2, F5, F8)
├─ Bootstrap₂ → Tree₂ (features: F1, F3, F7)
├─ Bootstrap₃ → Tree₃ (features: F1, F4, F9)
├─ Bootstrap₄ → Tree₄ (features: F2, F6, F10)
└─ Bootstrap₁₀₀ → Tree₁₀₀ (features: F3, F5, F8)

New Prediction:
├─ Input → Tree₁ → Prediction₁
├─ Input → Tree₂ → Prediction₂
├─ ...
├─ Input → Tree₁₀₀ → Prediction₁₀₀
│
└─ Final = Majority Vote(Pred₁, Pred₂, ..., Pred₁₀₀)
```

### Key Points

1. **No pruning needed** - Individual trees can grow deep
2. **Averaging overfitting** - Multiple trees prevent single tree's overfitting
3. **Parallel training** - All trees can be trained independently
4. **OOB evaluation** - Free test set available

## 8. Random Forest vs Decision Trees

### Comparison Table

| Aspect | Single Decision Tree | Random Forest |
|--------|-------------------|-----------------|
| **Overfitting** | High risk | Very low risk |
| **Training time** | Fast | Slower (multiple trees) |
| **Test time** | Very fast | Slower (all trees) |
| **Variance** | High | Low (averaging effect) |
| **Bias** | Low (flexible) | Low (many trees) |
| **Interpretability** | High (one tree) | Lower (many trees) |
| **Feature importance** | Single tree's view | Aggregate across all trees |
| **Outlier sensitivity** | High | Low |
| **Missing data handling** | Limited | Good (can impute) |
| **Scaling sensitivity** | None (tree-based) | None (tree-based) |

### Why Random Forest Wins

```
Single tree: High variance, prone to overfitting
                    ↓
Random Forest: Many different trees
                    ↓
Averaging predictions: Variance reduced by √T
                    ↓
Low variance + Low bias = Best generalization
```

## 10. Handling Missing Data

### The Challenge

**Missing data scenarios:**
1. Missing values in training data
2. Missing values in test data
3. Need predictions anyway!

### Random Forest Solution

**Two-phase approach:**

#### Phase 1: Initial Guess
```
For missing categorical value:
├─ Use most common class in training data
└─ Fill in this value

For missing numeric value:
├─ Use median of training data
└─ Fill in this value
```

#### Phase 2: Refined Estimate Using Proximity Matrix
```
Step 1: Run data through all trees
Step 2: Create proximity matrix
        (how often samples in same leaf)

Step 3: Find most similar samples
        (highest proximity scores)

Step 4: Use weighted average from similar samples
        Weight = proximity value
        Value = actual value of similar sample
```

### Example: Missing Weight Prediction

**Original dataset:**
```
Chest Pain | Blood Circ | Blocked Arteries | Weight | Heart Disease
No         | No         | No              | 125    | No
Yes        | Yes        | Yes             | 180    | Yes
Yes        | Yes        | No              | 210    | No
Yes        | No         | Yes             | 167    | Yes
```

**New sample with missing weight:**
```
Chest Pain | Blood Circ | Blocked Arteries | Weight | Heart Disease
Yes        | No         | ???              | ???    | ?
```

**Step 1: Initial Guess**
- Most common Blocked Arteries: No
- Median Weight: 167.5
- Fill: Blocked Arteries = No, Weight = 167.5

**Step 2: Run through trees to get proximity**

**Step 3: Calculate weighted average**
```
Most similar samples (by proximity):
├─ Sample 4 (proximity 0.8): Weight = 167
├─ Sample 1 (proximity 0.1): Weight = 125
└─ Sample 2 (proximity 0.1): Weight = 180

Weighted average:
= (0.8 × 167) + (0.1 × 125) + (0.1 × 180)
= 133.6 + 12.5 + 18
= 164.1

Final imputation: Weight ≈ 164
```

## 11. Proximity Matrix

### What is Proximity?

**Proximity(i, j)** = How often samples i and j end up in same leaf across all trees

```
Proximity ranges from 0 to 1:
0 = Never in same leaf (very different)
1 = Always in same leaf (identical)
```

### Creating Proximity Matrix

**Process:**
1. Run all samples through all trees
2. For each tree, note which samples land in same leaves
3. Count co-occurrences

**Example with 3 samples, 3 trees:**

| Sample Pair | Tree 1 | Tree 2 | Tree 3 | Total | Proximity |
|------------|--------|--------|--------|-------|-----------|
| (1,2) | Yes | Yes | No | 2/3 | 0.67 |
| (1,3) | Yes | No | No | 1/3 | 0.33 |
| (2,3) | No | No | Yes | 1/3 | 0.33 |

### Using Proximity Matrix

**Applications:**
1. **Missing data imputation** - Find most similar samples
2. **Outlier detection** - Low proximity to others = outlier
3. **Clustering** - Similarity-based grouping
4. **Visualization** - Dimensionality reduction
5. **Classification of new data** - Weight predictions by similarity

## 12. Working Example

### Dataset: Student Pass/Fail Prediction

```
Hours Studied | Sleep Hours | Pass
1            | 5          | No
2            | 6          | No
3            | 7          | Yes
4            | 6          | Yes
5            | 5          | Yes
6            | 4          | Yes
```

### Step 1: Create Bootstrap Samples

```
Bootstrap Sample 1:
Hours Studied | Sleep Hours | Pass
1            | 5          | No
2            | 6          | No
3            | 7          | Yes
4            | 6          | Yes
5            | 5          | Yes
5            | 5          | Yes  (duplicate)

Bootstrap Sample 2:
Hours Studied | Sleep Hours | Pass
2            | 6          | No
3            | 7          | Yes
4            | 6          | Yes
5            | 5          | Yes
6            | 4          | Yes

Bootstrap Sample 3:
Hours Studied | Sleep Hours | Pass
1            | 5          | No
2            | 6          | No
3            | 7          | Yes
6            | 4          | Yes
6            | 4          | Yes
```

### Step 2: Build Trees with Random Features

**Tree 1** (uses only Hours Studied):
```
If Hours Studied >= 3 → Yes, else No
```

**Tree 2** (uses only Sleep Hours):
```
If Sleep Hours >= 6 → Yes, else No
```

**Tree 3** (uses both features):
```
If Hours Studied >= 4 → Yes, else No
```

### Step 3: Make Predictions

**New student: 3 hours studied, 6 hours sleep**

```
Tree 1 (Hours >= 3):  Yes
Tree 2 (Sleep >= 6):  Yes
Tree 3 (Hours >= 4):  No

Final prediction by majority vote: Yes (2 Yes, 1 No)
```

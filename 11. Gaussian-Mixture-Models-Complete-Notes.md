## Why Gaussian Mixture Models

### The Power of Gaussian Distributions

**Properties:**
- By adjusting mean (μ) and variance (σ²), a Gaussian can approximate any elliptical shape
- Can create clusters of any elliptical form (not just spherical)
- Supported by Central Limit Theorem - real-world data often approximately normal

### Flexibility Advantages

**Gaussian Mixture Models (GMM) allow:**
1. **Multiple Clusters:** K different Gaussian distributions
2. **Different Shapes:** Each Gaussian has its own mean and covariance
3. **Soft Clustering:** Points have probability of belonging to each cluster
4. **Probabilistic:** Provides uncertainty/confidence in assignments

### GMM vs Hard Clustering

**Hard Clustering (K-Means):**
- Each point assigned to exactly one cluster
- Binary decision: belong or not
- Fast but rigid

**Soft Clustering (GMM):**
- Each point has probability for each cluster
- Probabilistic assignments
- More flexible, richer information

## Single Gaussian Distribution Review

### Univariate Gaussian

**Probability Density Function (PDF):**
```
N(x; μ, σ²) = (1/(√(2πσ²))) × exp(-(x-μ)²/(2σ²))
```

**Parameters:**
- μ (mu): mean - controls center of distribution
- σ² (sigma squared): variance - controls width/spread
- σ (sigma): standard deviation - square root of variance

**Maximum Likelihood Estimation (MLE) from Data:**

Given dataset {x₁, x₂, ..., xₙ}:

```
μ̂ = (1/n) × Σᵢ xᵢ          [Average of data points]
σ̂² = (1/n) × Σᵢ (xᵢ - μ̂)² [Average squared deviation from mean]
```

### Visual Interpretation

```
- Bell curve centered at μ
- Width determined by σ
- Larger σ = wider spread
- Smaller σ = tighter cluster
```

## Multivariate Normal Distribution

### Definition

**For d-dimensional data X = (x₁, x₂, ..., xₐ)ᵀ ∈ ℝᵈ**

**Parameters:**
- **μ** (mu-vector): d-dimensional mean vector
  ```
  μ = (μ₁, μ₂, ..., μₐ)ᵀ
  ```

- **Σ** (Sigma-matrix): d×d covariance matrix
  ```
  Σ = covariance matrix (symmetric, positive-definite)
  Σ⁻¹ = inverse of covariance matrix
  |Σ| = determinant of covariance matrix
  ```

**Probability Density Function:**
```
N(x; μ, Σ) = (1/((2π)^(d/2) × |Σ|^(1/2))) × 
             exp(-(1/2) × (x-μ)ᵀ × Σ⁻¹ × (x-μ))
```

### Interpretation of Covariance Matrix

**Diagonal Elements:** Variance in each dimension
- σ₁₁ = variance of x₁
- σ₂₂ = variance of x₂
- Larger value = more spread in that dimension

**Off-diagonal Elements:** Correlation between dimensions
- σ₁₂ = σ₂₁ = correlation between x₁ and x₂
- Positive = positive correlation
- Negative = negative correlation
- Zero = no correlation

### Maximum Likelihood Estimation for Multivariate

Given dataset {X₁, X₂, ..., Xₙ}:

```
μ̂ = (1/n) × ΣᵢXᵢ                    [Mean vector]

Σ̂ = (1/n) × Σᵢ(Xᵢ - μ̂)(Xᵢ - μ̂)ᵀ  [Covariance matrix]
```

## Gaussian Mixture Model Definition

### What is a GMM?

**A Gaussian Mixture Model** is a probabilistic model that represents data as drawn from K different multivariate Gaussian distributions, each with:
- Own mean vector: μₖ
- Own covariance matrix: Σₖ
- Mixing coefficient (prior): πₖ

### Model Parameters

**θ = {π, μ₁, ..., μₖ, Σ₁, ..., Σₖ}**

Where:
- **K:** Number of Gaussian components/clusters
- **πₖ:** Mixing coefficient (weight/prior for component k)
  - Represents proportion of data from component k
  - Σₖ πₖ = 1
  - 0 ≤ πₖ ≤ 1

- **μₖ:** Mean vector of component k
  - Kd parameters (d dimensions, K components)

- **Σₖ:** Covariance matrix of component k
  - K × d×d covariance matrices
  - Each is d×d symmetric positive-definite matrix

### Generative Process

How GMM generates data:

```
For each data point i:
  1. Select component k with probability πₖ
  2. Generate point from N(μₖ, Σₖ)
  3. Observation: Xᵢ (we see this)
  4. Hidden: Which component k was selected
```

### Total Probability Distribution

```
P(X) = Σₖ P(X|component k) × P(component k)
     = Σₖ N(X; μₖ, Σₖ) × πₖ
```

**Interpretation:** Mixture of K Gaussian distributions, weighted by mixing coefficients

## The Problem: Unknown Component Assignment

### The Core Challenge

**Scenario:** We observe data points and know K components, but don't know:
1. Which component generated each point?
2. What are the parameters μₖ and Σₖ?

**If we knew component assignments:** Could directly estimate parameters (calculate mean and covariance of each cluster)

**If we knew parameters:** Could calculate probability each point belongs to each component

**Chicken-and-egg problem!**

### Why Not Supervised?

- In supervised learning, we'd have labels saying which component each point belongs to
- GMM is **unsupervised** - no labels provided
- Must discover components from data alone

### Why EM is Perfect

EM naturally handles this:
- E-step: Estimate component assignments given current parameters
- M-step: Update parameters given assignments
- Iterate: Improve both simultaneously

## Latent Variables in GMM

### Introducing Latent Boolean Variables

To formalize the problem, we introduce latent (hidden) indicator variables:

**For each data point Xᵢ (i = 1 to n) and component k (k = 1 to K):**

```
Zᵢₖ = 1 if point Xᵢ was generated by component k
Zᵢₖ = 0 otherwise
```

**Constraint:** Exactly one Zᵢₖ is 1 for each point:
```
Σₖ Zᵢₖ = 1  for all i
```

### Vector Representation

**Latent vector for point Xᵢ:**
```
Zᵢ = (Zᵢ₁, Zᵢ₂, ..., Zᵢₖ)

Example: For K=3 and point i belongs to component 2:
Zᵢ = (0, 1, 0)
```

### Complete Probability Model

**Joint probability:**
```
P(Xᵢ, Zᵢ | θ) = Πₖ (πₖ × N(Xᵢ; μₖ, Σₖ))^Zᵢₖ
```

**For observed data X only (marginalizing over Z):**
```
P(Xᵢ | θ) = Σₖ πₖ × N(Xᵢ; μₖ, Σₖ)
```

## GMM with EM Algorithm

### Why EM for GMM?

**Optimal parameter estimation:** EM finds parameters that maximize likelihood
**Handles latent variables:** Naturally deals with unknown component assignments
**Soft clustering:** Provides probabilities, not hard assignments

### EM Structure for GMM

```
Initialize: Random or educated guess for π, μ₁,...,μₖ, Σ₁,...,Σₖ

Repeat until convergence:
  E-step:  Calculate responsibility γᵢₖ = P(component k | point Xᵢ)
  M-step:  Update parameters using responsibilities
```

### Convergence Monitoring

**Log-likelihood function:**
```
log L(θ) = Σᵢ log[Σₖ πₖ × N(Xᵢ; μₖ, Σₖ)]
```

- Should increase (or stay same) at each iteration
- Convergence when change is negligible (e.g., < 0.0001)
- Reaches local maximum

## E-Step for GMM

### Expectation Step: Calculate Responsibilities

**Responsibility γᵢₖ:** Probability that point Xᵢ belongs to component k

**Formula (using Bayes' theorem):**
```
γᵢₖ = P(component k | Xᵢ) 
    = P(Xᵢ | component k) × P(component k) / P(Xᵢ)
    
    = (N(Xᵢ; μₖ, Σₖ) × πₖ) / (Σⱼ N(Xᵢ; μⱼ, Σⱼ) × πⱼ)
```

**Intuition:**
- Numerator: Likelihood of point under component k × prior
- Denominator: Total probability of point under all components
- Result: Normalized probability (0 to 1)

### Interpretation

**γᵢₖ = 0.8** means: This point is probably from component k (80% confidence)

**γᵢₖ = 0.2** means: This point is probably not from component k (20% confidence)

**Sum property:**
```
Σₖ γᵢₖ = 1  for each point
```

### Effective Count

**How much responsibility does component k have for all data?**
```
Nₖ = Σᵢ γᵢₖ   (Total effective count of points in component k)
```

---

## M-Step for GMM

### Maximization Step: Update Parameters

Using the responsibilities γᵢₖ calculated in E-step, update parameters:

### 1. Update Mixing Coefficients π

**Formula:**
```
π̂ₖ = Nₖ / n = (Σᵢ γᵢₖ) / n
```

**Interpretation:**
- Numerator: Effective count of points belonging to k
- Denominator: Total number of points
- Result: Proportion of data in component k

### 2. Update Mean Vectors μ

**Formula:**
```
μ̂ₖ = (Σᵢ γᵢₖ × Xᵢ) / Nₖ = (Σᵢ γᵢₖ × Xᵢ) / (Σᵢ γᵢₖ)
```

**Interpretation:**
- Weighted average of data points
- Weight = responsibility for component k
- Points strongly assigned to k have more influence

### 3. Update Covariance Matrices Σ

**Formula:**
```
Σ̂ₖ = (Σᵢ γᵢₖ × (Xᵢ - μ̂ₖ) × (Xᵢ - μ̂ₖ)ᵀ) / Nₖ
```

**Interpretation:**
- Weighted covariance around updated mean
- Weight = responsibility for component k
- Points strongly assigned to k contribute more

## Comparison: GMM vs K-Means

### Hard vs Soft Assignment

| Aspect | K-Means | GMM |
|--------|---------|-----|
| **Assignment** | Hard (binary) | Soft (probabilistic) |
| **Output** | Cluster label | Probability distribution |
| **Cluster shape** | Usually spherical | Any elliptical shape |
| **Model** | Algorithmic | Probabilistic |

### K-Means as Special Case of GMM

**K-Means emerges when:**
- Assume all covariances = σ²I (identity matrix × variance)
- Use hard assignments (γᵢₖ ∈ {0,1})
- Mixture coefficients equal: πₖ = 1/K
- Covariance unknown or ignored

### Advantages of GMM over K-Means

✅ Probabilistic framework  
✅ Uncertainty in assignments  
✅ Can model non-spherical clusters  
✅ Principled model selection  
✅ Handles overlapping clusters  

### Advantages of K-Means

✅ Computationally faster  
✅ Simpler interpretation  
✅ Deterministic results  
✅ Better for very large datasets

## Worked Examples

### Example 1: 2D Data with 2 Gaussians

**Setup:**
- 2D points (x, y)
- 2 Gaussian components
- Unknown which point from which component

**Initial Parameters (random guess):**
```
Component 1: μ₁ = [1, 1], Σ₁ = I, π₁ = 0.5
Component 2: μ₂ = [3, 3], Σ₂ = I, π₂ = 0.5
```

**Data Points:**
```
X₁ = [0.5, 0.5]
X₂ = [1.0, 1.2]
X₃ = [3.2, 3.1]
X₄ = [2.8, 3.5]
```

### E-Step Iteration 1

**For X₁ = [0.5, 0.5]:**

Distance to μ₁ = √((0.5-1)² + (0.5-1)²) = √0.5 ≈ 0.71
Distance to μ₂ = √((0.5-3)² + (0.5-3)²) = √12.5 ≈ 3.54

```
N(X₁; μ₁, Σ₁) ∝ exp(-0.5 × 0.5) ≈ 0.61
N(X₁; μ₂, Σ₂) ∝ exp(-0.5 × 12.5) ≈ 0.000016

γ₁₁ = (0.61 × 0.5) / (0.61 × 0.5 + 0.000016 × 0.5) ≈ 0.999
γ₁₂ = 0.001
```

**Result:** X₁ is 99.9% from component 1, 0.1% from component 2

**Similar calculations for X₂, X₃, X₄:**
```
X₂: γ₂₁ ≈ 0.95, γ₂₂ ≈ 0.05  (Mostly component 1)
X₃: γ₃₁ ≈ 0.01, γ₃₂ ≈ 0.99  (Mostly component 2)
X₄: γ₄₁ ≈ 0.05, γ₄₂ ≈ 0.95  (Mostly component 2)
```

### M-Step Iteration 1

**Calculate effective counts:**
```
N₁ = 0.999 + 0.95 + 0.01 + 0.05 = 2.009 ≈ 2
N₂ = 0.001 + 0.05 + 0.99 + 0.95 = 1.991 ≈ 2
```

**Update mixing coefficients:**
```
π̂₁ = 2/4 = 0.5
π̂₂ = 2/4 = 0.5
```

**Update mean for component 1:**
```
μ̂₁ = (0.999×[0.5,0.5] + 0.95×[1.0,1.2] + 0.01×[3.2,3.1] + 0.05×[2.8,3.5]) / 2.009
   = ([0.4995 + 0.95 + 0.032 + 0.14] / 2.009, [0.4995 + 1.14 + 0.031 + 0.175] / 2.009)
   = ([1.6215] / 2.009, [1.8455] / 2.009)
   ≈ [0.81, 0.92]
```

**Update mean for component 2:**
```
μ̂₂ ≈ [3.19, 3.05]
```

### Iteration 2 and Beyond

Repeat with new parameters:
- E-step: Recalculate responsibilities γᵢₖ
- M-step: Update μ, Σ, π again
- Continue until convergence

**Expected Convergence:**
```
After 10-20 iterations:
Component 1: μ₁ ≈ [0.75, 0.85]  (clusters around X₁, X₂)
Component 2: μ₂ ≈ [3.0, 3.3]     (clusters around X₃, X₄)
```

## Practical Considerations

### Model Selection: How Many Components?

**Methods to determine K:**

1. **Cross-validation:** Try different K values on test data
2. **BIC (Bayesian Information Criterion):** Lower is better
   ```
   BIC = -2 log(L) + K×log(n)
   ```
3. **AIC (Akaike Information Criterion):**
   ```
   AIC = -2 log(L) + 2K
   ```
4. **Elbow Method:** Plot likelihood vs K, look for "elbow"

### Initialization Strategies

- **Random:** Pick random points as initial means
- **K-Means First:** Initialize with K-Means results
- **Domain Knowledge:** Use expert guidance
- **Multiple Runs:** Try several random initializations

### Convergence Issues

**Singularities:**
- If component shrinks to single point, covariance → 0
- Solutions: Add regularization, constrain variance

**Local Minima:**
- EM finds local maximum, not global
- Use multiple initializations
- Compare final likelihoods

### Numerical Stability

**Log-space computation:**
- Work with log probabilities
- Prevents underflow (very small numbers)
- Add small constant to covariance matrix

## Key Takeaways

- **Gaussian Mixture Models:** Probabilistic clustering with K Gaussians
- **Parameters:** Mixing coefficients π, means μ, covariances Σ
- **Soft Clustering:** Points have probability for each cluster
- **Why EM:** Handles chicken-and-egg problem of unknown assignments
- **E-Step:** Calculate responsibilities (component assignment probabilities)
- **M-Step:** Update parameters using weighted data
- **Advantages:** Flexible clusters, probabilistic framework
- **Applications:** Audio, speech, clustering, anomaly detection
- **vs K-Means:** GMM more flexible, K-Means faster
- **Model Selection:** Use BIC, AIC, or cross-validation

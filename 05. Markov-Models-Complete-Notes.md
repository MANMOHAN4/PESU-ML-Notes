## Limitation of IID Assumption

### IID Assumption
- **Independent:** Each observation is independent of all others
- **Identically Distributed:** All observations come from the same probability distribution

### When IID Fails
The IID assumption **does NOT hold** for many real-life scenarios:
- **Time series data:** Audio signals, video signals - future values depend on past values
- **Text sequences:** Probability of words occurring in a sentence - word choice depends on previous words
- **Biological sequences:** Base-pairs in a DNA strand - sequence structure has dependencies
- **Weather:** Tomorrow's weather depends on today's weather
- **Stock prices:** Today's price influences tomorrow's price

### Key Insight
Real-world data often exhibits **temporal dependencies** or **sequential dependencies**, where current observations are influenced by previous observations. Standard Bayesian approaches assuming independence cannot capture this.

## Stochastic Process

### Definition
A **stochastic process** is a collection of random variables indexed by an index set (typically time), where all the random variables draw values from a common state space.

### Key Characteristics
- **Indexed by time:** X₁, X₂, X₃, ..., Xₜ (often represented as {Xₜ})
- **Common state space:** All variables draw from same set of possible values
- **Random/probabilistic:** Each variable has a probability distribution
- **Sequence nature:** Order and temporal relationships matter

### Simple Example: Coin Tosses
- **Process:** Toss a coin N times
- **Output:** Vector of length N containing {H, T}
- **State space:** {H, T}
- **Stochastic:** Each toss is random, drawn from probability distribution
- **Not IID when dependencies exist:** Sequence patterns may repeat

## Markov Assumption

### Definition
A **Markov Process** is a specific kind of stochastic process that satisfies the **Markov Property**:

**"The future state depends only on the present state, and not on the past states."**

### Mathematical Formulation

**First-Order Markov Process:**
```
P(qₙ = a | q₁, q₂, ..., qₙ₋₁) = P(qₙ = a | qₙ₋₁)
```

**General k-Order Markov Process:**
```
P(qₙ = a | q₁, q₂, ..., qₙ₋₁) = P(qₙ = a | qₙ₋₁, qₙ₋₂, ..., qₙ₋ₖ)
```

### Interpretation
- **First-order:** Future depends on immediate past (1 state back)
- **k-order:** Future depends on k previous states
- **Memoryless property:** Can "forget" history beyond k steps

### Example: Weather
- **Simple Markov:** Tomorrow's weather depends only on today's weather
- **Higher-order:** Tomorrow's weather depends on today AND yesterday's weather

## Markov Chain

### Definition
A **Markov Chain** is a discrete-time stochastic process that satisfies the Markov property.

### Components
A Markov Chain consists of:
1. **Q:** A set of states {q₁, q₂, ..., qₙ}
2. **π:** Initial distribution (start probabilities)
3. **A:** Transition matrix (N × N matrix of transition probabilities)

### Mathematical Notation
- **N states:** Number of distinct states in the system
- **T time steps:** Sequence length or number of observations
- **λ (lambda):** Complete Markov chain characterized by λ(π, A)

---

## Markov Chain Parameters

### 1. Initial Distribution π

**Definition:** Probability that the first state in sequence is j

```
πⱼ = P(q₁ = j)
```

**Properties:**
- One value for each state
- All πⱼ values must sum to 1: Σⱼ πⱼ = 1
- Represents "starting preferences"

**Example:**
```
If N=3 states: Sunny (S), Cloudy (C), Windy (W)
π = {0.5, 0.3, 0.2}  means:
- P(start with Sunny) = 0.5
- P(start with Cloudy) = 0.3
- P(start with Windy) = 0.2
```

### 2. Transition Matrix A

**Definition:** Probability of moving from state i to state j

```
aᵢⱼ = P(qₜ₊₁ = j | qₜ = i)
```

**Properties:**
- N × N matrix (square)
- Each row represents current state i
- Each column represents next state j
- All rows sum to 1: Σⱼ aᵢⱼ = 1 for each row i
- aᵢⱼ ≥ 0 (probabilities are non-negative)

**Example Transition Matrix (3 states):**
```
     S    C    W
S  [0.4  0.3  0.3]
A = C  [0.2  0.5  0.3]
W  [0.1  0.2  0.7]
```

**Interpretation:**
- aₛₛ = 0.4: If today is Sunny, 40% chance tomorrow is Sunny
- aₛc = 0.3: If today is Sunny, 30% chance tomorrow is Cloudy
- aₛw = 0.3: If today is Sunny, 30% chance tomorrow is Windy

## Markov Chain: State Sequence Likelihood

### Problem Statement
**Given:** Markov Chain λ(π, A) and an observed sequence of states Q = {q₀, q₁, q₂, ..., qₘ}

**Find:** P(Q) - Likelihood that this sequence was observed

### Solution

**Probability Decomposition:**
```
P(Q) = P(q₀) × P(q₁|q₀) × P(q₂|q₁) × ... × P(qₘ|qₘ₋₁)
```

**Using Parameters:**
- P(q₀) comes from initial distribution π
- P(qᵢ|qᵢ₋₁) comes from transition matrix A

**Formula:**
```
P(Q) = πq₀ × aq₀q₁ × aq₁q₂ × ... × aqₘ₋₁qₘ

Or using product notation:
       m
P(Q) = πq₀ × ∏ aqᵢ₋₁,qᵢ
       i=1
```

### Computational Steps
1. Start with π value for first state
2. Multiply by transition probability from first to second state
3. Continue multiplying transition probabilities for entire sequence
4. Final product is likelihood

## Finding Markov Chain Parameters

### Given Multiple State Sequences
When you have several observed sequences, estimate π and A.

### Estimating Initial Distribution π

**Formula:**
```
πⱼ = (Number of sequences that start with state j) / (Total number of sequences)
```

**Important:** Sum of all π values must equal 1

### Estimating Transition Matrix A

**Formula for each aᵢⱼ:**
```
aᵢⱼ = (Number of transitions from state i to state j) / (Number of transitions that start from state i)
```

**Important:** Row sums of A must equal 1

### Step-by-Step Process
1. Go through all sequences
2. Count occurrences of each starting state → calculate π
3. Count all transitions from state i to state j → calculate A
4. Normalize to ensure probabilistic constraints

## Worked Example with Step-by-Step Solution

### Problem
**Given 14 sequences of weather states {Sunny (S), Cloudy (C), Windy (W)}:**

```
1. SCWSC      8. WCWCS
2. SNCSS      9. SWCWS
3. NCSWC     10. WWCCS
4. CWCWC     11. CCSWC
5. CWSSW     12. WCSWS
6. WCSCC     13. WSWCS
7. WCCWS     14. WSVSW
```

**Task:** Find Markov Chain parameters A and π

### Step 1: Calculate Initial Distribution π

Count sequences starting with each state:

```
Starting state counts:
- S (Sunny): Sequences 1, 2, 9 → count = 3
- C (Cloudy): Sequences 4, 5, 6, 11 → count = 4 (Note: Actually count from image = 3)
- W (Windy): Sequences 3, 7, 8, 10, 12, 13, 14 → count = 8 (Actually from image = 8)

Wait - verifying from original: Total = 14 sequences
Looking at actual image: π = {3/14, 3/14, 8/14}
```

**Calculation:**
```
πS = 3/14 ≈ 0.214
πC = 3/14 ≈ 0.214
πW = 8/14 ≈ 0.571

Verification: 3/14 + 3/14 + 8/14 = 14/14 = 1 ✓
```

### Step 2: Calculate Transition Matrix A

Count transitions from each state to each state.

**Transition: S → S (Sunny to Sunny)**
From sequence 1 (SCWSC): 0 transitions S→S
From sequence 2 (SNCSS): 0, then C→S (1), then S→S (1)
From sequence 9 (SWCWS): 0
Total S→S: Count occurrences...

For a 14-sequence dataset with transitions:
- Total transitions starting from S: Count all S occurrences (except last position)
- S to S transitions: Count occurrences where S is followed by S
- S to C transitions: Count occurrences where S is followed by C
- S to W transitions: Count occurrences where S is followed by W

**From the provided answer:**
```
A = |         | S     | C     | W     |
    | :------ | :---- | :---- | :---- |
    | S       | 2/15  | 4/15  | 9/15  |
    | C       | 9/19  | 4/19  | 6/19  |
    | W       | 9/22  | 12/22 | 1/22  |
```

### Step 3: Verify Results

**Check π normalization:**
```
πS + πC + πW = 3/14 + 3/14 + 8/14 = 1.0 ✓
```

**Check A row sums (each row must sum to 1):**

Row S (Sunny):
```
2/15 + 4/15 + 9/15 = 15/15 = 1.0 ✓
```

Row C (Cloudy):
```
9/19 + 4/19 + 6/19 = 19/19 = 1.0 ✓
```

Row W (Windy):
```
9/22 + 12/22 + 1/22 = 22/22 = 1.0 ✓
```

### Step 4: Interpretation

**Initial Distribution:**
- 21.4% chance sequence starts with Sunny
- 21.4% chance sequence starts with Cloudy
- 57.1% chance sequence starts with Windy

**Transitions from Sunny:**
- If today is Sunny: 13.3% chance Sunny tomorrow, 26.7% chance Cloudy, 60% chance Windy

**Transitions from Cloudy:**
- If today is Cloudy: 47.4% chance Sunny tomorrow, 21.1% chance Cloudy, 31.6% chance Windy

**Transitions from Windy:**
- If today is Windy: 40.9% chance Sunny tomorrow, 54.5% chance Cloudy, 4.5% chance Windy

### Example: Calculate Sequence Likelihood

**Sequence: S-C-W-S-C**

```
P(SCWSC) = πS × aS→C × aC→W × aW→S × aS→C
         = (3/14) × (4/15) × (6/19) × (9/22) × (4/15)
         = 0.214 × 0.267 × 0.316 × 0.409 × 0.267
         ≈ 0.00489
```

This likelihood value tells us how "typical" this weather sequence is given the learned Markov chain.

## Key Takeaways

- **Markov chains model temporal/sequential dependencies**
- **Markov property:** Future depends only on present, not entire history
- **Three parameters:** π (start), A (transitions), and state set Q
- **Two main tasks:** Calculate sequence likelihood or learn parameters from data
- **Foundation for HMMs:** Markov chains with hidden states and observations
- **Real applications:** Weather, stocks, speech, disease progression, text

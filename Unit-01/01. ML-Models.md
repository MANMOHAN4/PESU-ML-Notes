## 1. Formal Definition of Machine Learning

Machine Learning is a field of artificial intelligence that enables systems to learn from data and improve their performance without being explicitly programmed.

**Key Characteristics:**

- Learns from data (experience)
- Improves performance on specific tasks
- Generalizes to unseen data
- Adapts and evolves with new information

---

## 2. Machine Learning as a Flow

Machine Learning follows a systematic workflow:

```
Data Collection (80%)
        ↓
Data Preparation
        ↓
Model Selection
        ↓
Training
        ↓
Evaluation
        ↓
Deployment & Monitoring (20%)
```

The split typically involves:

- **80% effort:** Data collection, preparation, and preprocessing
- **20% effort:** Model selection, training, and optimization

---

## 3. Tom Mitchell's Definition

**Definition by Tom Mitchell:**

"Machine Learning is the study of algorithms that:

- improve their **performance P**
- at some **task T**
- with **experience E** (equate this to training data)."

A well-defined learning task is given by: **<P, T, E>**

### Breaking Down the Components:

| Component           | Meaning                   | Example                           |
| ------------------- | ------------------------- | --------------------------------- |
| **Task (T)**        | What the system should do | Playing chess, recognizing images |
| **Experience (E)**  | Training data or feedback | Historical games, labeled images  |
| **Performance (P)** | How to measure success    | Win rate, accuracy                |

---

## 4. PTE Framework: A Well-Posed ML Problem

To define a well-posed machine learning problem, you must identify:

1. **Task (T):** What is the system learning to do?
2. **Training Experience (E):** What data/feedback will it learn from?
3. **Performance Measure (P):** How do we evaluate if it learned well?

## 6. Seven Steps to Machine Learning

Machine Learning follows a systematic 7-step process:

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  STEP 1: Data Collection                               │
│  ↓                                                      │
│  STEP 2: Data Preparation                              │
│  ↓                                                      │
│  STEP 3: Choosing a Model                              │
│  ↓                                                      │
│  STEP 4: Training                                      │
│  ↓                                                      │
│  STEP 5: Evaluation                                    │
│  ↓                                                      │
│  STEP 6: Parameter Tuning                              │
│  ↓                                                      │
│  STEP 7: Prediction                                    │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### Detailed Explanation of Each Step:

**Step 1: Data Collection**

- Gather raw data from various sources
- Ensure sufficient quantity and quality
- Examples: sensor data, user feedback, transaction records

**Step 2: Data Preparation**

- Clean and preprocess data
- Handle missing values
- Normalize/scale features
- Remove outliers and noise
- Split into training and test sets

**Step 3: Choosing a Model**

- Select algorithm based on problem type
- Consider: Supervised vs Unsupervised, Regression vs Classification
- Examples: Decision Trees, Neural Networks, SVM, KNN

**Step 4: Training**

- Feed training data to the model
- Adjust internal parameters to minimize error
- Update weights/coefficients iteratively
- May take hours to months depending on data size

**Step 5: Evaluation**

- Test model on held-out test data
- Calculate performance metrics
- Metrics depend on problem type (accuracy, precision, recall, MSE, etc.)
- Check for overfitting/underfitting

**Step 6: Parameter Tuning**

- Adjust hyperparameters (learning rate, regularization, tree depth)
- Use techniques like cross-validation
- Try different model architectures
- Goal: Optimize performance on validation set

**Step 7: Prediction**

- Deploy trained model
- Make predictions on new, unseen data
- Monitor performance in production
- Retrain periodically with new data

## 7. Machine Learning Models Classification

### Three Main Categories:

```
                    Machine Learning
                           |
                ┌──────────┼──────────┐
                |          |          |
          SUPERVISED    UNSUPERVISED  REINFORCEMENT
          LEARNING      LEARNING      LEARNING
                |          |          |
        ┌───────┴─────┐    |      ┌────┴───┐
        |             |    |      |        |
    REGRESSION   CLASSIFICATION CLUSTERING ASSOCIATION
        |             |            |        |
    House Price    Spam Filter  Customer Market
    Prediction    Cancer Type   Segmentation Basket
                                 Anomaly   Analysis
```

### Detailed Classification:

#### **Supervised Learning**

**Definition:** Learning with labeled training data

**Has:** Input variables (X) + Output variables (Y)

**Goal:** Learn mapping function: **Y = f(X)**

**Types:**

1. **Regression** - Continuous output
   - Predicting house prices
   - Stock price forecasting
   - Salary prediction
2. **Classification** - Categorical output
   - Spam detection (spam/not spam)
   - Disease diagnosis (healthy/sick)
   - Image classification (cat/dog/bird)

#### **Unsupervised Learning (Exploratory Learning)**

**Definition:** Learning without labeled data; finding hidden patterns

**Types:**

1. **Clustering** - Group similar data points
   - Customer segmentation
   - Anomaly detection
   - Document categorization
2. **Association** - Find relationships between variables
   - Market basket analysis ("People who buy X also buy Y")
   - Gene expression analysis
   - Movie recommendations

#### **Reinforcement Learning**

**Definition:** Learning through trial and error with rewards/punishments

**Characteristics:**

- Agent interacts with environment
- Receives feedback (positive reward or negative penalty)
- Learns optimal policy over time
- No explicit labels provided

**Examples:**

- Game playing (AlphaGo, Chess)
- Robot control
- Autonomous driving

## 8. Supervised Learning - Detailed

### Core Principle:

Given: **Training data + Desired outputs (labels)**

**Step 1:** Models are trained using labeled dataset  
**Step 2:** Model learns about each type of data  
**Step 3:** Model is tested on test data  
**Step 4:** Predictions made for new instances

### Mathematical Formulation:

```
Training Data: {(x₁, y₁), (x₂, y₂), ..., (xₙ, yₙ)}

where:
  xᵢ = input features/attributes
  yᵢ = corresponding output label

Goal: Learn function f such that:
  y = f(x) for unseen data
```

The function approximation is called a **hypothesis function** (an approximation/claim about the true relationship).

### Example: Shape Recognition

**Problem:** Identify shapes based on their properties

**Training Data:**

```
Input: [4 sides, all equal, 90° angles]     → Output: Square
Input: [3 sides]                             → Output: Triangle
Input: [6 equal sides]                       → Output: Hexagon
```

**Training Process:**

- Model learns rules: "If 4 equal sides & 90° angles → Square"
- Model learns: "If 3 sides → Triangle"
- Model learns: "If 6 equal sides → Hexagon"

**Testing Phase:**

- New shape comes in: [4 sides, all equal]
- Model predicts: "Square"

### Types of Supervised Learning Algorithms:

#### **Regression Algorithms**

**When to use:** Output is continuous (real-valued)

**Examples:**

- Linear Regression
- Bayesian Linear Regression
- Support Vector Regression

**Applications:**

- House price prediction: $150,000 to $500,000
- Temperature forecasting: 15°C to 35°C
- Stock price prediction: $50 to $200 per share

#### **Classification Algorithms**

**When to use:** Output is categorical (discrete classes)

**Examples:**

- Decision Trees
- Random Forest
- Logistic Regression
- Support Vector Machines (SVM)
- Neural Networks

**Applications:**

- Spam detection: {Spam, Not Spam}
- Disease diagnosis: {Healthy, Sick, Critical}
- Image classification: {Cat, Dog, Bird}

### Supervised Learning Applications:

Real-world uses include:

- Email spam filtering
- Medical diagnosis
- Credit approval
- Customer churn prediction
- Fraud detection
- Sentiment analysis
- Face recognition

## 9. Unsupervised Learning - Detailed

### Core Principle:

**Given:** Training data WITHOUT desired outputs  
**Challenge:** No labels provided  
**Goal:** Find underlying structure, patterns, and similarities

### Key Characteristics:

- Models trained on unlabeled data
- Allowed to act without supervision
- Find hidden patterns and structure
- Group data by similarities
- Compress/represent data in meaningful way

### Process Example:

```
Raw Data (no labels)
      ↓
Apply clustering algorithm (e.g., K-means)
      ↓
Algorithm finds natural groupings
      ↓
Similar objects grouped together
      ↓
Output: Groups/Clusters
```

### Mathematical Process:

```
Input Data: {x₁, x₂, ..., xₙ} (no labels)

Step 1: Interpret raw data to find hidden patterns
Step 2: Apply suitable algorithm (k-means, hierarchical, etc.)
Step 3: Divide objects into groups based on:
        - Similarities (maximize within-group similarity)
        - Differences (maximize between-group differences)
```

### Types of Unsupervised Learning:

#### **Clustering**

**Definition:** Group objects into clusters such that:

- Objects in same cluster are most similar
- Objects in different clusters are least similar

**How it works:**

- Calculate similarity between all pairs
- Group similar items together
- Create boundaries between groups

**Algorithms:**

- K-Means clustering
- Hierarchical clustering
- DBSCAN
- Gaussian Mixture Models

**Applications:**

- Customer segmentation (group by behavior)
- Document clustering (group similar articles)
- Gene sequencing (group similar DNA patterns)
- Anomaly detection (find unusual groups)
- Image segmentation

#### **Association**

**Definition:** Find relationships and dependencies between variables

**Process:**

- Analyze large databases
- Find items that occur together frequently
- Determine strength of relationships

**Rule format:** IF condition THEN consequence

**Examples:**

1. **Market Basket Analysis:**
   - "People who buy bread AND milk often buy butter"
   - "People who buy diapers often buy beer"
   - Used for: store layouts, recommendations, promotions

2. **Gene Expression:**
   - "Subgroup of cancer patients with gene expression pattern A"
   - Used for: disease understanding, treatment groups

3. **Customer Behavior:**
   - "Customers who view product X often buy product Y"
   - Used for: recommendations, cross-selling

4. **Movie Ratings:**
   - "Movies rated high by user A are rated high by user B"
   - Used for: recommendation systems

### Unsupervised Learning Algorithms:

- K-means clustering
- Hierarchical clustering
- Anomaly detection
- Neural Networks (autoencoders)
- Principal Component Analysis (PCA)
- Independent Component Analysis (ICA)
- Apriori algorithm (association)
- Singular value decomposition (SVD)

### Unsupervised Learning Applications:

- Recommendation systems (Netflix, Amazon)
- Customer segmentation
- Anomaly detection (fraud, intrusion)
- Data compression
- Feature extraction
- Exploratory data analysis
- Market research

## 10. Reinforcement Learning - Detailed

### Core Concept:

**Reinforcement Learning is learning what to do and how to map situations to actions.**

The algorithm (agent) learns through trial and error:

- Evaluates current situation (state)
- Takes an action
- Receives feedback from environment
- Positive feedback = Reward
- Negative feedback = Penalty/Punishment
- Discovers which actions maximize reward

### Key Elements:

#### **Agent**

- Software program that makes intelligent decisions
- Learner in RL system
- Takes actions by interacting with environment
- Receives rewards based on actions

#### **Policy Function**

- Defines agent's behavior in environment
- Determines which action to perform
- Based on current state and past rewards/penalties
- Goal: Find optimal policy that maximizes total reward

#### **Value Function**

- Denotes how good it is for agent to be in particular state
- Depends on policy
- Denoted by: **v(s)**
- Equals: Total expected reward from that state onward

#### **Environment**

- Everything outside the agent
- Responds to agent's actions
- Provides state and reward information

### Learning Process:

```
Time steps: t = 0, 1, 2, 3, ...

At time t:
  Agent observes state: sₜ ∈ S
         ↓
  Agent produces action: aₜ ∈ A(sₜ)
         ↓
  Receives reward: rₜ₊₁ ∈ ℜ
         ↓
  Observes next state: sₜ₊₁
         ↓
  Updates policy based on reward
         ↓
  Repeats for next time step
```

### RL vs Other Learning Types:

| Aspect       | Supervised          | Unsupervised      | Reinforcement     |
| ------------ | ------------------- | ----------------- | ----------------- |
| **Labels**   | Provided            | Not provided      | Not provided      |
| **Feedback** | Correct actions     | Patterns          | Rewards/Penalties |
| **Goal**     | Map input to output | Find similarities | Maximize reward   |
| **Examples** | Classification      | Clustering        | Game playing      |

### Example 1: Dog Learning to Fetch Ball

**Scenario:**

```
Dog in room → Task: Learn to fetch ball

Trial 1: Dog runs and fetches ball → Gets cookie (reward)
Trial 2: Dog sits and waits → Gets no cookie (no reward)
Trial 3: Dog fetches ball → Gets cookie (reward)

Over time:
Dog learns: "Fetching ball = Cookie" (positive association)
Dog learns: "Sitting = No cookie" (negative association)

Final policy: Dog always fetches ball
```

**Key Learning:**

- No explicit instructions given
- Dog learns through experience
- Positive outcome reinforces behavior
- Negative outcome discourages behavior

### Example 2: Chess Board Scene (Training Pawn)

**Scenario:**

```
Game: Pawn (green box) vs Target (red box)

State S1: Pawn at position 1
Action A1: Move 2 steps forward
Result: Positive (moving toward target) → Reward R1

State S2: Pawn at new position
Action A2: Go straight (same direction)
Result: Negative (moving away) → Penalty

State S3: Similar to S1
Agent remembers: "Go diagonal gives heavy reward"
Action A3: Go diagonal
Result: Positive (kills target) → Heavy reward

Learning:
Agent discovers: "State S3 + Diagonal action = success"
Agent learns optimal policy for this type of situation
```

### Example 3: PacMan Game

**Environment:** Grid world with food, ghosts, PacMan

**Agent:** PacMan

**States:** Location of PacMan in grid

**Actions:** Move up, down, left, right

**Rewards:**

- +10 points: Eat food
- -100 points: Get killed by ghost
- Goal reward: Win the game (max cumulative reward)

**Learning Challenge:** Explore vs Exploit

- Explore: Try new paths to find food
- Exploit: Follow known profitable paths
- Balance both to maximize total reward

1. **Game Playing:**
   - AlphaGo defeated world champion at Go

2. **Robotics:**
   - Robot arm control

   - Industrial automation

3. **Energy Management:**

## 11. Generative vs Discriminative Models

### Classification:

Machine learning models can be classified into:

- **Discriminative Models**
- **Generative Models**

### Visual Analogy:

**Learning to identify cats vs dogs:**

- **Discriminative approach:** Learn the boundary/decision line between cats and dogs
  - Focus: "What makes cats different from dogs?"
  - Draw: Decision boundary in data space

- **Generative approach:** Learn how cats look, learn how dogs look
  - Focus: "How are cats distributed? How are dogs distributed?"
  - Generate: New examples that look like cats or dogs

### Mathematical Difference:

**Discriminative Models:**

- Learn: **P(Y|X)** - Probability of label given features
- Learn conditional probability directly
- Focus on classification boundary
- Better for classification tasks

**Generative Models:**

- Learn: **P(X|Y)** and **P(Y)** - Probability of features given label, and label probability
- Learn distribution of each class
- Can generate new data samples
- Better for understanding data distribution

### Key Distinction:

```
Data Space Visualization:

Discriminative Model:
┌─────────────────────────┐
│  ●●● ─────── ○○○        │
│      (boundary)         │
│  Cats          Dogs     │
└─────────────────────────┘
(Draws boundary between classes)

Generative Model:
┌─────────────────────────┐
│  ●●●        ○○○         │
│ (dense)    (dense)      │
│ Cat dist  Dog dist      │
│ Cats      Dogs          │
└─────────────────────────┘
(Models each class distribution)
```

### Discriminative Models:

**Definition:** Draws boundaries in data space

**Types:**

- Logistic Regression
- Support Vector Machine (SVM)
- Decision Tree
- Random Forest
- Neural Networks (feedforward)

**Advantages:**

- Often more accurate for classification
- Faster to train
- Less data typically needed

**Disadvantages:**

- Cannot generate new data
- Only learns decision boundary
- May miss underlying patterns

### Generative Models:

**Definition:** Models how data is placed throughout the space

**Types:**

- Bayesian Networks
- Hidden Markov Models (HMM)
- Autoregressive Models
- Generative Adversarial Networks (GANs)
- Gaussian Mixture Models (GMM)

**Advantages:**

- Can generate new synthetic data
- Understands data distribution
- Useful for unsupervised learning
- Can handle missing data

**Disadvantages:**

- Often more complex
- Requires more data
- Slower to train
- Harder to interpret

## Summary & Key Takeaways

### Framework for Understanding ML Problems:

Use PTE Framework for ANY ML problem:

1. **Task (T):** What should the system learn to do?
2. **Experience (E):** What data will it learn from?
3. **Performance (P):** How will we measure success?

### Three Paradigms:

| Type              | Data      | Feedback          | Use When                    |
| ----------------- | --------- | ----------------- | --------------------------- |
| **Supervised**    | Labeled   | Correct answers   | Have labeled data           |
| **Unsupervised**  | Unlabeled | None              | Exploring data patterns     |
| **Reinforcement** | None      | Rewards/Penalties | Agent learns through action |

### Seven Step Process:

Always follow: Data → Prepare → Model → Train → Evaluate → Tune → Predict

### Key Questions to Ask:

1. Do I have labels? → If YES: Supervised. If NO: Unsupervised or RL
2. Is output continuous or categorical? → Regression or Classification
3. Is goal to find patterns or make predictions? → Unsupervised or Supervised
4. Does system interact with environment? → Reinforcement

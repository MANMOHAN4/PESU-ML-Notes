## 1. Bias and Variance Concepts

### Definition

**Bias** (in statistics):

- The difference between an estimator's expected value and the true value of the parameter being estimated.
- Systematic error due to overly simple model assumptions.

**Variance** (in machine learning):

- The amount by which the performance of a predictive model changes when trained on different datasets from the same distribution.
- Sensitivity to training data variations.

### Optimal Situation

The ideal scenario: **Low Bias AND Low Variance**

- Bullets are concentrated together (low variance)
- And centered at the target/truth (low bias)
- This represents: Accurate and Consistent predictions

## 2. Understanding Bias in Regression

### Example: True Underlying Pattern

**Scenario:**

- Split data into training set (blue) and test set (green)
- True underlying pattern: Curved relationship

**Two Models to Compare:**

#### Model 1: Linear Regression

- Simple linear fit
- Hypothesis: Straight line through data
- Training Error: Some error present
- Test Error: Similar error level to training

**Characteristics:**

- High bias (underfits the data)
- Low variance (consistent across datasets)
- Unable to capture the curved pattern

#### Model 2: Complex (Squiggly) Fit

- Tries to fit all training data points exactly
- Hypothesis: Complex polynomial or spline
- Training Error: **Zero error** (perfect fit)
- Test Error: **Large error** (much worse than training)

**Characteristics:**

- Low bias (fits training pattern well)
- **High variance** (predictions change drastically with different datasets)
- Captured noise instead of true pattern

#### Model 3: Balanced Fit

- Mid-level complexity polynomial
- Training Error: Some error (between Models 1 and 2)
- Test Error: Similar to training error

**Characteristics:**

- Low bias (captures pattern reasonably well)
- Low variance (generalizes well to new data)
- **PREFERRED**: Best performance overall

## 4. Overfitting and Underfitting

### Overfitting

**Definition:** Model captures noise along with data pattern

**Characteristics:**

- Fits training data very well (low training error)
- Fails on test data (high test error)
- Gap between training and test error is large
- Models with this problem have: **Low Bias + High Variance**

**Causes:**

- Model too complex for problem
- Too many parameters relative to data
- Training for too many iterations
- No regularization applied

**Solutions:**

- Reduce model complexity
- Use regularization (L1/L2)
- Get more training data
- Use cross-validation
- Early stopping

### Underfitting

**Definition:** Model fails to even capture pattern of data

**Characteristics:**

- Does not fit training data well (high training error)
- Test error similar to training error (both high)
- Models with this problem have: **High Bias + Low Variance**

**Causes:**

- Model too simple for problem
- Insufficient features
- Wrong algorithm choice
- Insufficient training
- Too much regularization

**Solutions:**

- Increase model complexity
- Add more relevant features
- Reduce regularization strength
- Train longer
- Use better algorithm

## 5. Bias-Variance Tradeoff

### Key Insight

There exists a fundamental tradeoff between bias and variance. As we change model complexity:

### The Tradeoff Process

**Phase 1: Complexity Increases, Bias Decreases**

- Model becomes more flexible
- Can capture more patterns
- Training error decreases
- Initial decrease in bias is steep

**Phase 2: Variance Starts Increasing**

- Model becomes sensitive to training data
- Different datasets produce different predictions
- Initial increase in variance is gradual

**Phase 3: Total Error Behavior**

- Initially: Total error **decreases**
  - Reason: Bias reduction > Variance increase
  - Net effect is improvement

- At Optimal Complexity:
  - Bias and variance are balanced
  - Total error is minimized
  - Best generalization performance

- Beyond Optimal:
  - Total error **increases**
  - Reason: Variance increase > Bias reduction
  - Net effect is deterioration
  - Model is overfitting

### Graphical Understanding

```
Error
  |     Total Error
  |    /          \
  |   /            \
  |  /   Bias ↓     \  Variance ↑
  | /                 \
  |/___________________\_____ Model Complexity
       ↑
   Optimal Complexity
```

### Mathematical Perspective

**Total Error = Bias² + Variance + Irreducible Error**

- As complexity increases:
  - Bias² decreases (toward zero)
  - Variance increases (toward data fit)
  - Irreducible error stays constant

## 6. Error Decomposition

### Components of Prediction Error

The expected prediction error at a point can be decomposed into three components:

#### 1. **Irreducible Error (σ²)**

**Definition:** Error that cannot be reduced by any model

**Characteristics:**

- Caused by inherent noise in data
- Stochastic nature of relationships
- Measurement errors
- Unobserved confounding variables
- Even perfect models cannot reduce this

**Example:** Predicting human height

- Even knowing all genetics and environment
- There's inherent biological variability
- This is irreducible error

**Cannot be reduced by:**

- Better algorithms
- More data
- More features
- More compute

#### 2. **Bias² (Systematic Error)**

**Definition:** Difference between average predicted value and true function

**Measurement:**

```
Bias² = (E[ŷ] - f_true)²
where E[ŷ] = average prediction across all possible training sets
```

**Interpretation:**

- Measures how far off predictions are on average
- Systematic error in the same direction
- Due to model assumptions being wrong

**Reduction Methods:**

- Increase model complexity
- Add relevant features
- Remove wrong assumptions
- Use better algorithm

#### 3. **Variance (Sensitivity to Data)**

**Definition:** Expected variation in predictions across different training datasets

**Measurement:**

```
Variance = E[(ŷ - E[ŷ])²]
where E[ŷ] = average prediction across all possible training sets
```

**Interpretation:**

- How much predictions fluctuate
- Measures sensitivity to training data variations
- High variance = different datasets give very different models

**Reduction Methods:**

- Decrease model complexity
- Use regularization
- Get more training data
- Ensemble methods

## 7. Finding Bias and Variance in Practice

### Challenge in Higher Dimensions

In 2D: Easy to plot and visualize bias/variance by looking at decision boundary

In High Dimensions: Cannot visualize - need quantitative approach

### Quantitative Approach Using Error Analysis

#### Step 1: Train Multiple Models

Example: Cat vs Dog classifier

| Model   | Train Error | Test Error | Diagnosis                 |
| ------- | ----------- | ---------- | ------------------------- |
| Model 1 | 1%          | 11%        | High Variance             |
| Model 2 | 15%         | 16%        | High Bias                 |
| Model 3 | 15%         | 30%        | High Bias + High Variance |
| Model 4 | 0.5%        | 1%         | Low Bias + Low Variance   |

#### Step 2: Analyze Training Error

**Training Error indicates BIAS:**

- **Low training error** (< Bayes error): Low bias ✓
- **High training error** (> Bayes error): High bias ✗

#### Step 3: Analyze Test Error Gap

**Gap (Test - Training) indicates VARIANCE:**

- **Small gap** (similar): Low variance ✓
- **Large gap** (test >> training): High variance ✗

### Decision Criteria

#### High Variance (Low Bias Scenario)

- **Signal:** Low training error, High test error
- **Gap:** Large (10% or more)
- **Diagnosis:** Model fits training perfectly but fails on test
- **Example:** Model 1 (1% train, 11% test)
- **Solution:** Reduce complexity, regularize, more data

#### High Bias (Low Variance Scenario)

- **Signal:** High training error, Similar high test error
- **Gap:** Small (similar errors)
- **Diagnosis:** Model underfits, doesn't capture pattern
- **Example:** Model 2 (15% train, 16% test)
- **Solution:** Increase complexity, add features, remove assumptions

#### High Bias + High Variance

- **Signal:** High training error AND high test error
- **Gap:** Large
- **Diagnosis:** Wrong approach for problem
- **Example:** Model 3 (15% train, 30% test)
- **Solution:** Completely change algorithm/features

#### Low Bias + Low Variance

- **Signal:** Low training error AND low test error
- **Gap:** Very small
- **Diagnosis:** Excellent model
- **Example:** Model 4 (0.5% train, 1% test)
- **Action:** This is what we want!

## 8. Worked Example: Error Decomposition

### Problem Setup

**True underlying function:** y = 2x

**Input range:** x ∈ {1, 2, 3}

**Noise:** ε ~ N(0, 1) (normal distribution, mean=0, variance=1)

**Actual values:**
| x | y |
|---|---|
| 1 | 2 |
| 2 | 4 |
| 3 | 6 |

### Three Training Datasets with Noise

**Training Set 1:**
| x | y |
|---|------|
| 1 | 1.8 |
| 2 | 3.9 |
| 3 | 5.7 |
Model fit: **y = 3.8** (constant model)

**Training Set 2:**
| x | y |
|---|------|
| 1 | 2.1 |
| 2 | 3.4 |
| 3 | 5.6 |
Model fit: **y = 3.7** (constant model)

**Training Set 3:**
| x | y |
|---|------|
| 1 | 2.4 |
| 2 | 3.3 |
| 3 | 6.1 |
Model fit: **y = 3.93** (constant model)

### Calculate Bias²

**Test point:** x₀ = 2

**True value:** f_true(2) = 2 × 2 = 4

**Model predictions:**

- From Dataset 1: f₁(2) = 3.8
- From Dataset 2: f₂(2) = 3.7
- From Dataset 3: f₃(2) = 3.93

**Average prediction:**

```
f̄(2) = (3.8 + 3.7 + 3.93) / 3 = 11.43 / 3 = 3.81
```

**Bias Calculation:**

```
Bias = f̄(2) - f_true(2) = 3.81 - 4 = -0.19

Bias² = (-0.19)² = 0.0361
```

**Interpretation:** Model systematically underpredicts by 0.19 on average

### Calculate Variance

**Formula:**

```
Variance = E[(ŷ - E[ŷ])²]
         = Average squared deviation from mean prediction
```

**Deviations from mean (3.81):**

- Dataset 1: 3.8 - 3.81 = -0.01
- Dataset 2: 3.7 - 3.81 = -0.11
- Dataset 3: 3.93 - 3.81 = 0.12

**Squared deviations:**

- Dataset 1: (-0.01)² = 0.0001
- Dataset 2: (-0.11)² = 0.0121
- Dataset 3: (0.12)² = 0.0144

**Variance Calculation:**

```
Variance = (0.0001 + 0.0121 + 0.0144) / 3
         = 0.0266 / 3
         = 0.00887
```

**Interpretation:** Predictions vary moderately across different training sets

### Calculate Total Expected Error

**Total Error = Bias² + Variance + Irreducible Error**

**Given:**

- Noise distribution: ε ~ N(0, 1)
- Irreducible Error (σ²) = 1

**Calculation:**

```
Total Error = 0.0361 + 0.00887 + 1
            = 1.045
```

**Breakdown:**

- Irreducible error: 1.0000 (95.7%)
- Bias²: 0.0361 (3.5%)
- Variance: 0.0089 (0.8%)

**Interpretation:**

- Most error comes from inherent noise (irreducible)
- Some error from systematic underprediction (bias)
- Little error from model variability (variance)
- Model is **stable but slightly wrong**

## Key Takeaways

**Critical Insights:**

1. Bias and variance are inverses - reducing one increases the other
2. The goal is to find the **sweet spot** that minimizes total error
3. Train error indicates bias; test-train gap indicates variance
4. Irreducible error is fundamental - always present
5. Different models may have high bias in some regions and high variance in others

**Practical Strategy:**

- Start simple (if underfitting, increase complexity)
- Monitor both training and test error
- Look for the point where test error stops decreasing
- Use regularization to combat overfitting
- Consider ensemble methods for stability

**Remember:**
The bias-variance tradeoff is a fundamental principle in machine learning. The art is finding the right balance for your specific problem!

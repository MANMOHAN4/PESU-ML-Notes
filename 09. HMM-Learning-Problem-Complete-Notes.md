## Problem Statement

### The Learning Problem
**Given:**
- Multiple observation sequences O₁, O₂, ..., Oₖ
- Number of hidden states N

**Find:**
- λ* = Model parameters λ*(π, A, B) that maximize probability of observed sequences

**Mathematically:**
```
λ* = argmax_λ [∏ᵢ P(Oᵢ | λ)]

or equivalently:
λ* = argmax_λ [∑ᵢ log P(Oᵢ | λ)]
```

### Key Question
**"What HMM model best explains the training data?"**

## Why Learning Matters

### Real-World Scenario
You have training data (observation sequences) but don't know the underlying model parameters.

**Example: Speech Recognition**
- **Data:** Audio recordings of speakers saying words
- **Labels:** Words spoken (observations are acoustic features)
- **Unknown:** How many phoneme states? What transitions? What emissions?
- **Goal:** Learn HMM parameters that model speech

### Three Types of HMM Problems

| Problem | Given | Find | Algorithm |
|---------|-------|------|-----------|
| **Likelihood** | O, λ | P(O\|λ) | Forward Algorithm |
| **Decoding** | O, λ | Q* | Viterbi Algorithm |
| **Learning** | O, N | λ* | Baum-Welch Algorithm |

All three are essential for complete HMM systems.

## The Challenge: Unknown Hidden States

### Why Learning is Different

**In Likelihood and Decoding problems:**
- Know the hidden states (explicitly or can estimate paths)
- Can compute directly

**In Learning problem:**
- Don't know hidden states
- Don't know parameters
- Catch-22: Need states to learn parameters, need parameters to infer states

### The Chicken-and-Egg Problem

```
To learn transition probabilities A:
  Need: Count transitions from state i to state j
  Required: Know which hidden states occurred
  Problem: States are hidden!

To infer hidden states:
  Need: Transition and emission probabilities
  Required: Know A and B
  Problem: Don't know them yet!
```

### Solution: Expectation-Maximization (EM)

**Idea:** 
1. Start with random parameter estimates
2. **E-step:** Use current parameters to estimate hidden states (expectations)
3. **M-step:** Use state estimates to update parameters (maximization)
4. Repeat until convergence

## Gamma (γ) Probability

### Definition

**γₜ(j) = P(qₜ = j | O, λ)** = Probability of being in state j at time t, **given entire observation sequence**

### Interpretation

- "How likely is state j to be the hidden state at time t?"
- Marginal probability over all paths (unlike Viterbi which finds best path)
- Uses complete observation sequence (not just to time t)

### Calculation Using Forward-Backward

**Formula:**
```
γₜ(j) = (αₜ(j) × βₜ(j)) / P(O|λ)

Where:
- αₜ(j) = forward probability (observations up to t)
- βₜ(j) = backward probability (observations from t+1 onward)
- P(O|λ) = ∑_i αₜ(i) × βₜ(i) (normalizing constant)
```

### Practical Calculation

**Step 1:** Compute α and β matrices using forward-backward algorithms

**Step 2:** For each time t and state j:
- Multiply: αₜ(j) × βₜ(j)
- Normalize by column sum: divide by ∑_i αₜ(i) × βₜ(i)

**Normalization ensures:** ∑_j γₜ(j) = 1 for each t

### Interpretation

High γₜ(j) means:
- Time t state j is likely
- Consistent with entire observation sequence

## Xi (ξ) Probability

### Definition

**ξₜ(i,j) = P(qₜ = i, qₜ₊₁ = j | O, λ)** = Joint probability of being in state i at time t and state j at time t+1, **given entire observation sequence**

### Interpretation

- "How likely is the transition i→j at time t?"
- Probability of specific transition, not just states
- Used to estimate transition probabilities A

### Calculation

**Formula:**
```
ξₜ(i,j) = (αₜ(i) × aᵢⱼ × b_j(oₜ₊₁) × βₜ₊₁(j)) / P(O|λ)

Where:
- αₜ(i) = probability of observations up to t in state i
- aᵢⱼ = transition probability i→j
- b_j(oₜ₊₁) = emission probability at j for next observation
- βₜ₊₁(j) = probability of future observations given state j
- P(O|λ) = normalizing constant
```

### Visual Representation

```
        t=i          t=i+1
       State i -----> State j
                aij
       
αt(i)    ---->    βt+1(j)
         observe oT+1
         bj(oT+1)
```

### Relationship to Gamma

**Key relationship:**
```
∑_j ξₜ(i,j) = γₜ(i)  (summing over all next states gives current state probability)
```

## Baum-Welch Algorithm

### Overview

**Baum-Welch Algorithm** = EM algorithm applied to HMMs

**Core Idea:** Iteratively refine model parameters using expected counts

### Algorithm Structure

```
1. Initialize A, B, π with random values
2. Repeat until convergence:
   a) E-step: Calculate γ and ξ using current parameters
   b) M-step: Update A, B, π using γ and ξ
   c) Check convergence (likelihood increasing?)
3. Return final λ(π, A, B)
```

---

## E-Step: Expectation

### Calculate Probabilities

**Using current parameters λ:**

```
1. Forward algorithm: Calculate αₜ(j) for all t, j
2. Backward algorithm: Calculate βₜ(j) for all t, j
3. Calculate γₜ(j) = (αₜ(j) × βₜ(j)) / ∑_i αₜ(i) × βₜ(i)
4. Calculate ξₜ(i,j) = (αₜ(i) × aᵢⱼ × b_j(oₜ₊₁) × βₜ₊₁(j)) / ∑_i ∑_j [...]
```

### Interpretation

- **γₜ(j):** Expected probability of being in state j at time t
- **ξₜ(i,j):** Expected probability of transition i→j at time t

These "expected counts" are used in next step.

---

## M-Step: Maximization

### Update Initial Distribution π

**Formula:**
```
π̂ⱼ = γ₁(j)
```

**Interpretation:** 
- Probability of starting in state j
- Equals expected state at t=1

### Update Transition Matrix A

**Formula:**
```
âᵢⱼ = (∑ₜ₌₁^(T-1) ξₜ(i,j)) / (∑ₜ₌₁^(T-1) γₜ(i))
```

**Interpretation:**
- Numerator: Expected count of transitions from i to j
- Denominator: Expected count of being in state i
- Ratio: Proportion of times leaving state i that go to j

### Update Emission Matrix B

**Formula:**
```
b̂ⱼ(k) = (∑ₜ s.t. oₜ=k γₜ(j)) / (∑ₜ₌₁^T γₜ(j))
```

**Interpretation:**
- Numerator: Expected count of being in state j when symbol k observed
- Denominator: Expected count of being in state j (any symbol)
- Ratio: Proportion of state j occurrences that emit symbol k

## Complete Algorithm with Worked Example

### Baum-Welch Pseudocode

```
procedure BAUM_WELCH(observation sequences O, number of states N):
    initialize A, B, π with random values
    
    iteration ← 0
    while not converged do
        iteration ← iteration + 1
        
        // E-STEP
        α ← FORWARD(O, A, B, π)
        β ← BACKWARD(O, A, B, π)
        
        for all t, j do
            γ[t, j] ← (α[t, j] × β[t, j]) / (∑_i α[t, i] × β[t, i])
        
        for all t, i, j do
            ξ[t, i, j] ← (α[t, i] × A[i, j] × B[j, o[t+1]] × β[t+1, j]) / 
                           (∑_i ∑_j [...])
        
        // M-STEP
        // Update initial distribution
        for all j do
            π̂[j] ← γ[1, j]
        
        // Update transition matrix
        for all i, j do
            â[i, j] ← (∑ₜ ξ[t, i, j]) / (∑ₜ γ[t, i])
        
        // Update emission matrix
        for all j, k do
            b̂[j, k] ← (∑ₜ s.t. o[t]=k γ[t, j]) / (∑ₜ γ[t, j])
        
        // Replace old parameters
        A ← â
        B ← b̂
        π ← π̂
        
        // Check convergence
        if likelihood not improving significantly then
            break
    
    return A, B, π
```

### Example: Weather HMM Learning

**Given:**
- Single observation sequence: O = {H, G, H} (Happy, Grumpy, Happy)
- Number of hidden states: N = 2 (Sunny, Rainy)
- Starting parameters: Random initialization

**Iteration 1:**

Assume initial random parameters:
```
π⁽⁰⁾ = {0.5, 0.5}
A⁽⁰⁾ = {[0.6, 0.4], [0.3, 0.7]}
B⁽⁰⁾ = {[0.7, 0.3], [0.4, 0.6]}
```

**E-step:** Calculate α, β, γ, ξ using these parameters (would show detailed calculations - similar to likelihood/decoding examples)

**M-step:** Update parameters

Example calculation for new transition:
```
â_SS = (∑ₜ ξₜ(S,S)) / (∑ₜ γₜ(S))
      = (ξ₁(S,S) + ξ₂(S,S)) / (γ₁(S) + γ₂(S))
      
Let's say:
      = (0.15 + 0.12) / (0.5 + 0.55)
      = 0.27 / 1.05
      ≈ 0.257
```

Example calculation for new emission:
```
b̂_S(Happy) = (γ₁(S) + γ₃(S)) / (γ₁(S) + γ₂(S) + γ₃(S))
           = (0.5 + 0.48) / (0.5 + 0.55 + 0.48)
           = 0.98 / 1.53
           ≈ 0.640
```

**Iteration N:** Repeat until convergence

Typically 10-100 iterations for good results.

## For Multiple Observation Sequences

### When You Have K Training Sequences

**Extend formulas:**
```
πⱼ = (1/K) ∑_{k=1}^K γₜ₌₁^(k)(j)

âᵢⱼ = ∑_{k=1}^K ∑ₜ₌₁^(Tₖ-1) ξₜ^(k)(i,j) / ∑_{k=1}^K ∑ₜ₌₁^(Tₖ-1) γₜ^(k)(i)

b̂ⱼ(m) = ∑_{k=1}^K ∑ₜ s.t. oₜ^(k)=vₘ γₜ^(k)(j) / ∑_{k=1}^K ∑ₜ γₜ^(k)(j)
```

**Key:** Sum over all sequences, then normalize.

## Using HMM in Practice

### Typical Workflow

**Step 1: Problem Specification**
- Define what the HMM solves
- Specify whether HMM is suitable

**Step 2: Decide Observation Sequence**
- What observations will we use?
- What represents the external manifestation of hidden states?

**Step 3: Prepare Training Data**
- Collect observation sequences for training
- Collect validation sequences

**Step 4: Model Design**
- Interpret what hidden states represent
- Decide number of hidden states N
- Design HMM architecture

**Step 5: Train HMM**
- Use Baum-Welch algorithm
- Use training observation sequences

**Step 6: Validate Model**
- Test on validation sequences
- Evaluate performance (likelihood, etc.)

**Step 7: Iterate and Refine**
- Adjust N if needed
- Collect more training data if needed
- Repeat training and validation

**Step 8: Use Trained HMM**
- For new instances: Solve likelihood, decoding, or other problems
- Use trained λ* parameters

### Real Application Examples

**1. Speech Recognition**
- States: Phonemes
- Observations: Acoustic features (MFCCs)
- Learn: Phoneme models from speech data

**2. Gesture Recognition**
- States: Gesture phases
- Observations: Hand/body positions
- Learn: Gesture models from motion capture

**3. Gene Prediction**
- States: Coding vs. non-coding regions
- Observations: DNA base pairs
- Learn: Region models from annotated DNA

## Practical Issues in HMM Learning

### 1. What Do States Represent?
- **No unique answer** - Application specific
- Designer chooses interpretation
- Example: In speech, states = phonemes

### 2. How Many Hidden States?
- **No unique answer** - Domain dependent
- Too few: Model too simple
- Too many: Overfitting, slow training
- **Strategies:**
  - Start with rough estimate
  - Use statistical measures
  - Domain knowledge
  - Trial and error

### 3. Numerical Instability
- Probabilities become very small (underflow)
- Products of many small numbers → zero
- **Solution:** Use log-space arithmetic
  - Work with log-probabilities
  - Convert to log-space before computation
  - Results equivalent but numerically stable

### 4. Local Optima
- Baum-Welch finds local maximum, not global
- Random initialization affects final result
- **Solutions:**
  - Try multiple random initializations
  - Use domain knowledge for initialization
  - Accept local optima (usually good enough)

### 5. Convergence Speed
- More states → slower convergence
- Longer sequences → slower convergence
- Typical: 10-100 iterations for convergence

## Key Takeaways

- **Learning problem:** Find HMM parameters that best explain training data
- **Challenge:** Hidden states unknown, parameters unknown (chicken-and-egg problem)
- **Solution:** Baum-Welch algorithm (EM for HMMs)
- **E-step:** Calculate expected state counts using forward-backward
- **M-step:** Update parameters using expected counts
- **γ probability:** State probability given full sequence
- **ξ probability:** Transition probability given full sequence
- **Iterative:** Repeat until parameters converge
- **Applications:** Train models for speech, gestures, biology, etc.
- **Practical issues:** Numerical stability, local optima, state design

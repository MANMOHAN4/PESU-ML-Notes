## Problem Statement

### The Decoding Problem
**Given:**
- Hidden Markov Model λ(π, A, B)
- Observation sequence O = {o₁, o₂, ..., oₜ}

**Find:**
- Q* = Most probable sequence of hidden states that generated O

**Mathematically:**
```
Q* = argmax_Q P(Q | O, λ)
```

### Key Difference from Likelihood Problem

| Aspect | Likelihood Problem | Decoding Problem |
|--------|-------------------|------------------|
| **Given** | Observations + Model | Observations + Model |
| **Find** | P(O\|λ) | Q* (best state sequence) |
| **Operation** | Sum over all sequences | Max over all sequences |
| **Use** | Model evaluation | State sequence inference |

### Real-World Applications

**1. Speech Recognition**
- **Observations:** Acoustic signal features
- **Hidden states:** Phonemes (speech units)
- **Task:** Find most likely phoneme sequence
- **Significance:** Recognize which word was spoken

- **Hidden states:** Actual disease state of patient
- **Task:** Find most likely disease progression
- **Significance:** Diagnose underlying disease

- **Hidden states:** Actual gestures being performed
- **Task:** Recognize which gesture is being made

- **Observations:** Sequence of words
- **Hidden states:** Entity types (Person, Location, Organization)
- **Task:** Identify entity types for each word
- **Significance:** Extract named entities from text

## Brute Force Solution

### Approach
For every possible hidden state sequence Q of length T:
1. Calculate P(O, Q) = P(O | Q) × P(Q)
2. Find Q with maximum probability

### Mathematical Formulation

**For a specific state sequence Q = {q₁, q₂, ..., qₜ}:**
```
P(O, Q) = π_q1 × b_q1(o1) × a_q1,q2 × b_q2(o2) × ... × a_qT-1,qT × b_qT(oT)
```

**Find maximum:**
```
Q* = argmax_Q [P(O, Q)]
   = argmax_Q [π_q1 × ∏ᵢ aᵢ,ᵢ₊₁ × b_i+1(oᵢ₊₁)]
```

### Computational Complexity

**Calculations per sequence:**
- Each state sequence requires: 2T multiplications

**Total operations:**
- Number of sequences: N^T
- Operations per sequence: 2T
- **Total: O(T × N^T) multiplications**

### Comparison to Likelihood Problem

**Likelihood problem:**
- Uses sum: Σ_Q P(O, Q)
- Brute force: Still exponential

**Decoding problem:**
- Uses max: max_Q P(O, Q)
- Brute force: Still exponential
- Same computational issues!

**Solution needed:** Can we use a similar trick (dynamic programming)?

## Viterbi Algorithm

### Core Idea
Replace sum with max to compute best path efficiently using dynamic programming.

### Definition: Viterbi Path Probability

**δₜ(j) = max_{q1,...,qt-1} P(q₁, ..., qₜ₋₁, qₜ = j, o₁, ..., oₜ | λ)**

**Interpretation:**
- Maximum probability of any path ending in state j at time t
- After observing o₁ through oₜ
- "Best path so far" to reach state j

### Recursive Computation

**Initialization (t=1):**
```
δ₁(j) = πⱼ × b_j(o₁)
```

**Recursion (t=2 to T):**
```
δₜ(j) = max_i [δₜ₋₁(i) × aᵢⱼ] × b_j(oₜ)
```

**Termination:**
```
P(O, Q*) = max_j δₜ(j)
```

### Key Insight: Optimal Substructure

**If Q* is the optimal path:**
- Any prefix of Q* is also optimal
- This enables dynamic programming
- Can build solution incrementally

### Viterbi Algorithm Pseudocode

```
procedure VITERBI(observations of len T, state-graph of len N):
    viterbi ← new matrix[N][T]
    backpointer ← new matrix[N][T]
    
    // Initialization
    for states j from 1 to N do
        viterbi[j, 1] ← π_j × b_j(o₁)
        backpointer[j, 1] ← 0  (no previous state)
    
    // Recursion
    for timestamp t from 2 to T do
        for states j from 1 to N do
            maxProb ← 0
            argmaxState ← 0
            
            for previous states i from 1 to N do
                prob ← viterbi[i, t-1] × a_{i,j}
                if prob > maxProb then
                    maxProb ← prob
                    argmaxState ← i
            
            viterbi[j, t] ← maxProb × b_j(o_t)
            backpointer[j, t] ← argmaxState
    
    // Termination
    maxFinalProb ← 0
    finalState ← 0
    for states j from 1 to N do
        if viterbi[j, T] > maxFinalProb then
            maxFinalProb ← viterbi[j, T]
            finalState ← j
    
    // Backtrack to find best path
    bestPath ← new array[T]
    bestPath[T] ← finalState
    for t from T down to 2 do
        bestPath[t-1] ← backpointer[bestPath[t], t]
    
    return bestPath, maxFinalProb
```

### Computational Complexity

**Time complexity:**
- At each time step t: N states × N previous states = O(N²)
- Total for T steps: O(N² × T)
- **Same efficiency as forward algorithm!**

## Back-Pointers in Viterbi

### What are Back-Pointers?

**Back-pointer** = pointer to the previous state in the best path

**Role:**
- Remember which previous state led to current state
- Used to reconstruct the optimal state sequence
- Essential for finding the actual path, not just its probability

### How Back-Pointers Work

**At each step:**
1. Calculate probability of reaching state j from all previous states i
2. Find i that gives maximum probability
3. Store i as back-pointer for state j at time t

**At the end:**
1. Start from final state with maximum probability
2. Follow back-pointers backward through time
3. Reconstruct complete optimal path

### Example Structure

```
Time:    t=1        t=2        t=3
         S (0.8)    S (0.096)  S (0.0973)
                    ← bp=S     ← bp=S
         R (0.2)    R (0.112)  R (0.0346)
                    ← bp=S     ← bp=R
```

**Backtracking:**
- At t=3, best is S with prob 0.0973, bp=S
- At t=2, bp points to S with prob 0.096, bp=S
- At t=1, bp points to S with prob 0.8
- **Best path: S → S → S**

## Worked Examples

### Example 1: Weather and Mood HMM

**Parameters:**
```
States: Sunny (S), Rainy (R)
Observations: Happy (H), Grumpy (G)

π = {2/3, 1/3}

A = [0.8  0.2]
    [0.4  0.6]

B = [0.8  0.2]
    [0.4  0.6]
```

**Observation sequence:** O = {H, G, H}

**Task:** Find Q* = best hidden state sequence

### Step 1: Initialization (t=1, observation=H)

```
δ₁(S) = π_S × b_S(H) = (2/3) × 0.8 = 8/15 ≈ 0.533
δ₁(R) = π_R × b_R(H) = (1/3) × 0.4 = 2/15 ≈ 0.133

backpointer₁(S) = 0
backpointer₁(R) = 0
```

### Step 2: First Recursion (t=2, observation=G)

**For state S at t=2:**
```
Path via S: δ₁(S) × a_SS = (8/15) × 0.8 = 6.4/15
Path via R: δ₁(R) × a_RS = (2/15) × 0.4 = 0.8/15

Maximum: 6.4/15 from S
δ₂(S) = max(6.4/15, 0.8/15) × b_S(G) = (6.4/15) × 0.2 = 1.28/15 ≈ 0.085
backpointer₂(S) = S
```

**For state R at t=2:**
```
Path via S: δ₁(S) × a_SR = (8/15) × 0.2 = 1.6/15
Path via R: δ₁(R) × a_RR = (2/15) × 0.6 = 1.2/15

Maximum: 1.6/15 from S
δ₂(R) = max(1.6/15, 1.2/15) × b_R(G) = (1.6/15) × 0.6 = 0.96/15 ≈ 0.064
backpointer₂(R) = S
```

### Step 3: Second Recursion (t=3, observation=H)

**For state S at t=3:**
```
Path via S: δ₂(S) × a_SS = (1.28/15) × 0.8 = 1.024/15
Path via R: δ₂(R) × a_RS = (0.96/15) × 0.4 = 0.384/15

Maximum: 1.024/15 from S
δ₃(S) = max(1.024/15, 0.384/15) × b_S(H) = (1.024/15) × 0.8 = 0.8192/15 ≈ 0.0546
backpointer₃(S) = S
```

**For state R at t=3:**
```
Path via S: δ₂(S) × a_SR = (1.28/15) × 0.2 = 0.256/15
Path via R: δ₂(R) × a_RR = (0.96/15) × 0.6 = 0.576/15

Maximum: 0.576/15 from R
δ₃(R) = max(0.256/15, 0.576/15) × b_R(H) = (0.576/15) × 0.4 = 0.2304/15 ≈ 0.0154
backpointer₃(R) = R
```

### Step 4: Backtracking

```
Best final state: S (prob = 0.0546 > 0.0154)

From t=3:
- Best state: S
- backpointer₃(S) = S → go to S at t=2

From t=2:
- Best state: S
- backpointer₂(S) = S → go to S at t=1

From t=1:
- Best state: S
```

**Optimal hidden state sequence:** Q* = {S, S, S}

**Probability:** P(O, Q*) ≈ 0.0546

### Example 2: Interpretation

**What does this mean?**
- Given observation sequence {Happy, Grumpy, Happy}
- Most likely explanation: Weather was {Sunny, Sunny, Sunny}
- Even though middle observation was Grumpy (which is somewhat unlikely from Sunny)

**Why Sunny-Sunny-Sunny over other paths?**
- Sunny → Sunny is strong transition (a_SS = 0.8)
- Sunny emits Happy with high probability (b_S(H) = 0.8)
- Rainy transitions are less probable
- Overall path probability is highest for SSS

## Comparison: Likelihood vs Decoding

### Likelihood Problem
```
P(O|λ) = ∑_Q P(O, Q)
Forward algorithm: Compute by summing all paths
Result: Single probability value
Interpretation: How likely is this observation sequence?
```

### Decoding Problem
```
Q* = argmax_Q P(O, Q)
Viterbi algorithm: Find maximum probability path
Result: State sequence
Interpretation: What is the most probable explanation?
```

### Why Both Matter

- **Likelihood:** Model evaluation and selection
- **Decoding:** Understanding what happened (state inference)

They answer different questions about the same data.

## Key Takeaways

- **Decoding problem:** Find most probable hidden state sequence given observations
- **Brute force:** Exponential complexity O(T × N^T) - infeasible
- **Viterbi algorithm:** O(N² × T) dynamic programming solution
- **Back-pointers:** Enable reconstruction of optimal path
- **Applications:** Speech recognition, POS tagging, disease diagnosis, gesture recognition
- **Similar to forward algorithm:** But uses max instead of sum for path reconstruction

## High Dimensional Data Problem

### Definition

**High Dimensional Data:** p >> N
- p = number of features
- N = number of observations
- Examples: 1000 features but only 50 samples

### Examples of High Dimensional Data

**Healthcare Data:**
- Patient records with thousands of measurements
- Gene expression data (thousands of genes)

**Financial Data:**
- Stock prices with hundreds of features
- Complex trading indicators

**Genomics:**
- DNA microarray data (50,000+ genes)
- Gene sequencing information

### Why is High Dimensionality a Problem?

**Problem 1: Insufficient Data**
- When p >> N, impossible to find deterministic relationship
- Model cannot distinguish real patterns from noise
- Overfitting likely

**Problem 2: Sparse Space**
- Data becomes increasingly sparse as dimensions increase
- Distance metrics become less meaningful
- All points appear equally far apart

**Problem 3: Computational Complexity**
- Algorithm runtime increases with dimensionality
- Memory requirements grow exponentially
- Many algorithms become infeasible

**Problem 4: Visualization**
- Cannot visualize data beyond 3 dimensions
- Difficult to explore and understand data
- Harder to find insights

---

## Curse of Dimensionality

### What is Curse of Dimensionality?

**Phenomenon:** Model performance degrades as dimensionality increases

### Effects on Algorithms

**Classification Problems:**
- High dimensional sparse space = few training examples per region
- Cannot properly train classifier
- Poor generalization to test data

**Clustering Problems:**
- Density and distance become less meaningful
- All points appear approximately same distance
- Clustering algorithms struggle

**Regression Problems:**
- More features than samples = infinite solutions
- Cannot determine unique relationship
- Poor predictive performance

### Visualization of Effect

```
1D: Points spread along line
    ●  ●    ●    ●  ●
    
2D: Points spread in plane (more sparse)
    ●     ●  
    
         ●    ●
    
    ●           ●
    
3D+: Exponentially sparser distribution
     (impossible to visualize but worse)
```

## Dimensionality Reduction Techniques

### Main Approaches

**1. Feature Elimination**
- Remove features that don't contribute to prediction
- **Pros:** Easy to interpret, prevents overfitting
- **Cons:** Information loss, may discard useful signals

**2. Feature Extraction**
- Create new features from combinations of old features
- **Pros:** Retains most valuable information, more efficient
- **Cons:** New features harder to interpret

### Popular Dimensionality Reduction Techniques

| Technique | Type | Description |
|-----------|------|-------------|
| **PCA** | Linear | Creates uncorrelated principal components |
| **SVD** | Linear | Matrix factorization approach |
| **ICA** | Linear | Independent component analysis |
| **t-SNE** | Non-linear | t-distributed stochastic neighbor embedding |
| **Autoencoder** | Non-linear | Neural network compression |
| **ISOMAP** | Non-linear | Preserves geodesic distances |

## Principal Component Analysis (PCA) - Introduction

### Definition

**PCA** is a statistical procedure that:
- Converts correlated variables into uncorrelated variables
- Finds directions of maximum variance
- Projects high-dimensional data into lower-dimensional space
- Retains maximum information while reducing dimensions

### Intuitive Understanding

**Question:** What's the strongest trend in the data?
- **Answer:** First principal component (PC1)
- Captures direction with maximum variance

**Question:** What's the next strongest trend, perpendicular to PC1?
- **Answer:** Second principal component (PC2)
- Uncorrelated with PC1

**Question:** And the next strongest trend, perpendicular to both PC1 and PC2?
- **Answer:** Third principal component (PC3)
- And so on...

### Why Maximum Variance?

**Philosophy:** Directions with high variance contain signal
**Result:** Low variance directions are noise
**Action:** Keep high variance components, discard low variance

---

## PCA Fundamentals

### Principal Components Characteristics

**1. Rank Ordered by Variance**
- PC1 has highest variance
- PC2 has second highest variance
- And so on...

**2. Uncorrelated**
- Components are orthogonal (perpendicular)
- Zero correlation between components
- Independent information in each component

**3. Linear Combination**
- Each component is weighted combination of original features
- PC = a₁×Feature₁ + a₂×Feature₂ + ... + aₚ×Featureₚ

**4. Orthogonal**
- Literally perpendicular to each other in feature space
- In statistics: uncorrelated = orthogonal

**5. Capture Maximum Variation**
- Keep few components with high variance
- Discard many components with low variance
- Minimal information loss

### Example: 2D to 1D Reduction

```
Original 2D data:          After PCA (1D projection):
  ▲                          |●
  │    ●●                    |●
  │  ●    ●                  |●
  │●        ●    ────>       |●
  │  ●    ●                  |
  │    ●●                    |
  └──────────►               |
    
Blue line = PC1 (direction of max variance)
Red line = PC2 (discarded, low variance)
```

## PCA Algorithm Steps

### Step 1: Standardization

**Why:** Equalize feature scales
- Features with large values dominate PCA
- Standardization ensures equal treatment

**Process:**
```
For each feature:
1. Calculate mean (μ)
2. Calculate standard deviation (σ)
3. Standardized_feature = (feature - μ) / σ

Result: Mean = 0, Standard deviation = 1
```

**Example:**
```
Feature: [10, 20, 30, 40, 50]
Mean = 30, StdDev = 15.81

Standardized: [-1.26, -0.63, 0, 0.63, 1.26]
```

### Step 2: Compute Covariance Matrix

**Purpose:** Measure correlations between features

**Formula:**
```
For p features:
Cov = (1/n) × X^T × X

Where X = standardized data matrix
```

**Interpretation:**
- **Diagonal:** Variance of each feature (should all be 1 after standardization)
- **Off-diagonal:** Covariance between feature pairs
- High covariance = features related

**Example (2D):**
```
Covariance matrix:
     [1.0   0.8]
     [0.8   1.0]

Positive 0.8: Features positively correlated
```

### Step 3: Calculate Eigenvalues and Eigenvectors

**Purpose:** Find directions of maximum variance

**Definitions:**
- **Eigenvector:** Direction in feature space
- **Eigenvalue:** Amount of variance in that direction

**Mathematical Relationship:**
```
Cov × v = λ × v

Where:
- Cov = covariance matrix
- v = eigenvector
- λ = eigenvalue
```

**Finding:**
1. Solve characteristic equation: det(Cov - λI) = 0
2. Get eigenvalues: λ₁, λ₂, ..., λₚ
3. For each λᵢ, find eigenvector vᵢ

**Example:**
```
Eigenvalues: [8.22, 0.38]
Eigenvectors: v₁ = [0.69, 1.0]ᵀ, v₂ = [-1.0, 0.69]ᵀ
```

### Step 4: Rank Components

**Process:**
1. Sort eigenvalues in descending order
2. Corresponding eigenvectors are principal components
3. Largest eigenvalue = PC1, second largest = PC2, etc.

### Step 5: Choose Number of Components

**Options:**
1. **Variance explained:** Keep components explaining 90-95% variance
2. **Scree plot:** Look for "elbow" in eigenvalue plot
3. **Domain knowledge:** Choose based on problem

### Step 6: Create Projection Matrix

**Formation:**
```
Feature vector = [v₁, v₂, ..., vₖ]ᵀ

Where:
- k = chosen number of components
- vᵢ = eigenvector for PC_i
```

**Dimensions:**
- Original features: p
- New components: k (k < p)
- Projection matrix: p × k

### Step 7: Transform Data

**Formula:**
```
New data = Original data × Feature vector
Z = X × W

Where:
- X = original data (n × p)
- W = feature vector (p × k)
- Z = transformed data (n × k)
```

**Result:** k-dimensional representation of original data

## PCA Mathematical Details

### Eigendecomposition

**Covariance matrix decomposition:**
```
Cov = V × Λ × V^T

Where:
- V = matrix of eigenvectors (columns)
- Λ = diagonal matrix of eigenvalues
- V^T = transpose of V
```

### Variance Explained

**By single component:**
```
Variance(PC_i) = λᵢ / Σⱼ λⱼ

Where:
- λᵢ = eigenvalue for component i
- Σ λⱼ = sum of all eigenvalues
```

**Cumulative variance:**
```
Cumulative = Σᵢ₌₁^k λᵢ / Σⱼ₌₁^p λⱼ

Usually keep when cumulative ≥ 0.90 (90%)
```

**Example:**
```
Eigenvalues: [8.22, 0.38]
Total variance = 8.22 + 0.38 = 8.60

PC1 explains: 8.22 / 8.60 = 95.6%
PC2 explains: 0.38 / 8.60 = 4.4%

Keep only PC1 → retain 95.6% variance, reduce dimensions 50%
```

## PCA Worked Example

### Data

**Points:**
```
P1 = (2, 1)
P2 = (3, 5)
P3 = (4, 3)
P4 = (5, 6)
P5 = (6, 7)
P6 = (7, 8)
```

### Step 1: Calculate Mean

```
Mean_x = (2+3+4+5+6+7)/6 = 4.5
Mean_y = (1+5+3+6+7+8)/6 = 5.0

Mean = (4.5, 5.0)
```

### Step 2: Center Data

**Subtract mean:**
```
P1 - Mean = (2-4.5, 1-5.0) = (-2.5, -4)
P2 - Mean = (3-4.5, 5-5.0) = (-1.5, 0)
P3 - Mean = (4-4.5, 3-5.0) = (-0.5, -2)
P4 - Mean = (5-4.5, 6-5.0) = (0.5, 1)
P5 - Mean = (6-4.5, 7-5.0) = (1.5, 2)
P6 - Mean = (7-4.5, 8-5.0) = (2.5, 3)
```

### Step 3: Calculate Covariance Matrix

```
Cov = (1/6) × [centered_data^T × centered_data]

Cov_xx = (1/6) × [(-2.5)² + (-1.5)² + (-0.5)² + 0.5² + 1.5² + 2.5²]
       = (1/6) × [6.25 + 2.25 + 0.25 + 0.25 + 2.25 + 6.25] = 2.92

Cov_yy = (1/6) × [(-4)² + 0² + (-2)² + 1² + 2² + 3²]
       = (1/6) × [16 + 0 + 4 + 1 + 4 + 9] = 5.67

Cov_xy = (1/6) × [(-2.5)×(-4) + (-1.5)×0 + (-0.5)×(-2) + 0.5×1 + 1.5×2 + 2.5×3]
       = (1/6) × [10 + 0 + 1 + 0.5 + 3 + 7.5] = 3.67

Covariance Matrix:
    [2.92  3.67]
    [3.67  5.67]
```

### Step 4: Calculate Eigenvalues

**Characteristic equation:**
```
(2.92 - λ)(5.67 - λ) - 3.67² = 0
16.56 - 2.92λ - 5.67λ + λ² - 13.47 = 0
λ² - 8.59λ + 3.09 = 0

Solutions: λ₁ = 8.22, λ₂ = 0.38
```

### Step 5: Calculate Eigenvectors

**For λ₁ = 8.22:**
```
[2.92 - 8.22   3.67    ] [x] = [0]
[3.67      5.67 - 8.22 ] [y]   [0]

-5.3x + 3.67y = 0
3.67x - 2.55y = 0

x = 0.69y

Normalized eigenvector v₁ = [0.69, 1.0]ᵀ
```

### Step 6: Project Data

**Using PC1 (first eigenvector):**
```
Projection = centered_data × v₁

Example for P1:
Z₁ = (-2.5, -4) · (0.69, 1.0) = -2.5×0.69 + (-4)×1.0 = -5.73

All projections: [-5.73, -1.38, -2.84, 1.38, 3.84, 6.73]
```

### Result

**1D representation from 2D:**
- Original data: 2 dimensions
- After PCA: 1 dimension
- Variance retained: 95.6%
- Dimensionality reduced: 50%

## Singular Value Decomposition (SVD)

### Definition

**SVD** decomposes a matrix A into three matrices:
```
A = U × Σ × V^T

Dimensions:
- A: m × n matrix
- U: m × m (left singular vectors)
- Σ: m × n (singular values on diagonal)
- V^T: n × n (right singular vectors transposed)
```

### Interpretation (Movie Recommendation Example)

Imagine user-movie rating matrix:

```
Users × Movies = U × Σ × V^T

U tells about users' preferences
Σ shows importance of each factor
V^T tells about movie characteristics
```

### Properties of SVD

**Singular Values (Σ diagonal):**
- Always non-negative
- Ordered: σ₁ ≥ σ₂ ≥ ... ≥ σₘᵢₙ ≥ 0
- Related to matrix rank

**Left Singular Vectors (U columns):**
- Orthonormal vectors
- Span row space of A

**Right Singular Vectors (V^T rows):**
- Orthonormal vectors
- Span column space of A

### Relationship to PCA

```
For data matrix X (centered):
- Covariance matrix: Cov = X^T × X
- SVD of X: X = U × Σ × V^T

Then:
- X^T × X = V × Σ² × V^T
- Eigenvectors of X^T X = columns of V
- Eigenvalues of X^T X = σᵢ²
```

**Connection:** Principal components = right singular vectors!

---

## SVD Definition and Properties

### Full SVD vs Reduced SVD

**Full SVD:** A = U × Σ × V^T
- U: m × m
- Σ: m × n (with zeros)
- V^T: n × n

**Reduced SVD:** Keep only r largest singular values
- U_r: m × r
- Σ_r: r × r
- V_r^T: r × n
- Much smaller, similar information

### Low-Rank Approximation

**Truncate SVD to rank k:**
```
A_k = U_k × Σ_k × V_k^T

Uses only k largest singular values
Approximates original matrix
Useful for compression
```

### Frobenius Norm Error

**Reconstruction error:**
```
||A - A_k||_F = √[Σᵢ₌ₖ₊₁ σᵢ²]

Lower k → larger error
Higher k → smaller error but more memory
```

```
    [0  0  1]
```

## PCA vs SVD

### Conceptual Difference

| Aspect | PCA | SVD |
|--------|-----|-----|
| **Approach** | Statistical | Algebraic |
| **Focus** | Covariance structure | Matrix factorization |
| **Requires** | Centered data | Any matrix |
| **Output** | Principal components | Singular vectors |

### Computational Difference

**PCA:**
1. Center data
2. Compute covariance matrix
3. Find eigendecomposition
4. Project data

**SVD:**
1. Apply SVD directly to data matrix
2. Right singular vectors = PCA components
3. Project data

### Practical Equivalence

**For centered data X:**
```
PCA: X = U × Σ × V^T (via SVD)
     Principal components = columns of V
     
OR

PCA: X^T × X = V × Σ² × V^T (eigendecomposition)
     Principal components = eigenvectors of X^T X
```

**Result:** Same principal components!

### Why Use One vs Other?

**Use PCA when:**
- Working with centered data
- Want statistical interpretation
- Need to understand variance structure

**Use SVD when:**
- Have non-square matrices
- Need numerical stability
- Doing low-rank approximation
- Want computational efficiency

## Choosing Number of Components

### Method 1: Variance Explained Threshold

**Rule:** Keep components explaining 90-95% variance

```
k = smallest k such that:
(∑ᵢ₌₁^k λᵢ) / (∑ᵢ₌₁^p λᵢ) ≥ 0.90
```

**Example:**
```
Eigenvalues: [8.22, 0.38]
Total: 8.60

PC1: 8.22/8.60 = 95.6% → Keep PC1, discard PC2
```

### Method 2: Scree Plot

**Process:**
1. Plot eigenvalues in descending order
2. Look for "elbow" point
3. Keep components before elbow

```
Eigenvalue
    │
    │ ╱
    │╱ ← Steep decline
    ├─ Elbow point (optimal k)
    │    └─
    │        └─
    │           └── Gradual decline (noise)
    │
    └─────────────► Component
```

### Method 3: Kaiser Criterion

**Rule:** Keep components with eigenvalue ≥ 1

```
For standardized data (mean=0, std=1):
Only keep components with λ ≥ 1
```

### Method 4: Cumulative Variance Plot

**Plot:**
```
Cumulative
Variance    │
  100%      ├─────────
   90%      ├───────╱
   80%      ├──────╱
   70%      ├─────╱
            ├────╱
            │   ╱
            └──╱────────► Number of components
               k chosen
```

## Practical Considerations

### When PCA Works Well

✅ Linear relationships between features  
✅ High-dimensional data  
✅ Correlated features to remove  
✅ Want visualization in 2D/3D  
✅ Preprocessing for supervised learning  

### When PCA May Not Work

❌ Non-linear relationships  
❌ Need to preserve local structure  
❌ Categorical features  
❌ Interpretability critical (components are combinations)  
❌ Outliers present (affects covariance)

### Tips for Using PCA

1. **Standardize first** - Always standardize data
2. **Check for outliers** - Remove or handle separately
3. **Scree plot** - Visualize variance explained
4. **Validate choice of k** - Check performance on task
5. **Document components** - Understand what each component represents
6. **Consider non-linear** - Use t-SNE, autoencoders if needed

## Key Takeaways

- **High dimensional data** → Curse of dimensionality
- **PCA** → Linear dimensionality reduction, variance maximization
- **Principal components** → Uncorrelated, rank-ordered by variance
- **PCA steps** → Standardize → Covariance → Eigendecomposition → Project
- **SVD** → Matrix factorization, related to PCA via eigenvectors
- **Choose k** → Variance threshold, scree plot, or domain knowledge
- **Applications** → Face recognition, image compression, preprocessing
- **Trade-off** → Fewer dimensions vs information loss
